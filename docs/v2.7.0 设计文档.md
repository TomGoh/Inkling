## 1. 背景与目标

v2.7.0 针对一批长期积压的真实缺陷与体验缺口（Issue #121 ~ #134）进行集中攻坚，覆盖模式切换同步、插入链接交互、快照数据安全、外部修改盲区、快捷键冲突、异步竞态、导出解绑、搜索反馈、设置易用性、图片异常处理、保存冲突呈现、多窗口同步与草稿体积护栏等 14 个维度。

目标是：在不引入新架构的前提下，逐一对齐各 Issue 的复现路径与诉求，交付真实可用、可被回归验证的修复。

## 2. 核心修复与技术方案

### 2.1 模式切换位置与滚动同步（#121）

- **快照注入守卫恢复**：`Editor.tsx` 恢复 `sourceMode && enterSnapshot` 渲染守卫，确保 CodeMirror 挂载时携带真实快照（含非零光标与非零滚动）。
- **滚动持续缓存**：`Editor.tsx` 监听 `.editor-scroll` 滚动事件，持续缓存 `scrollTop` 至 `wysiwygScrollTopRef`，规避切换瞬间 `display:none` 重排导致滚动读取被钳 0。
- **退出侧映射**：`useSourceModeTransition.ts` 退出源码模式时通过 `getSourceModeScroll(filePath)` 读取活着的 CM 实例，依据两端 `scrollHeight` 用 `mapScrollTop` 做**比例映射**还原滚动位置（`src/lib/source-mode-cursor.ts`）。
- **配套测试**：`useSourceModeTransition.test.ts`、`source-mode-navigation.test.ts` 覆盖非零快照捕获与退出滚动/选区恢复。

### 2.2 Ctrl+K 插入链接应用内对话框（#122）

- 移除 `src/lib/useGlobalShortcuts.ts` 中原生阻塞的 `window.prompt`。
- 新增 `src/components/Editor/LinkDialog.tsx`：支持同时输入链接文本与 URL，选中文本预填，Esc / backdrop 关闭，焦点管理完整，彻底剔除浏览器级对话框的粗糙体验。

### 2.3 删除快照 localStorage 配额保护（#123）

- `src/store/workspace/shared.ts` 新增 `probeSnapshotStorageHealth()`：估算已占用字符数并对目标 key 实测可写性，返回 `writable / sizeChars / entryCount`。
- `src/store/workspace/fileTree.ts` 快照写入失败时向用户展示**可见错误提示**（`showMessage` error 级别，明确"未保存内容将丢失"），不再仅用 `console.warn` 静默吞掉。
- `src/components/Sidebar/DeletedSnapshots.tsx` 面板展示健康状态：`writable=false` 显示备份不可写告警，占用接近配额上限时提示精简。
- **配套测试**：`tests/store/filetree-snapshot-feedback.test.ts`（新增）用真实 QuotaExceededError 驱动失败分支。

### 2.4 外部文件变更监听盲区与删除标记（#124）

- `src/lib/useFileWatcher.ts` 监听范围扩大至全部 `openTabs`，ENOENT 标记 `deletedOnDisk`。
- `switchTab` 核验磁盘 mtime：
  - 外部修改且本地无改动 → `reloadFile` 以磁盘内容为准；
  - 有本地改动 → 置 `conflictPending` 并拉起 `useConflict.openConflict`（复用 #132 冲突链路）；
  - 仅桌面端（`isTauri()`）执行 mtime 比对，浏览器 mock 环境不误判"外部修改"。
- **配套测试**：`tests/unit/file-watcher-opentabs.test.tsx` 新增非 dirty→reload、dirty→conflict 两分支用例。

### 2.5 快捷键自定义冲突检测补齐保留组合（#125）

- `src/store/shortcuts.ts` 的 `RESERVED_SHORTCUTS` 黑名单补全全部硬编码组合：`mod+s`、`mod+n`、`mod+shift+f`、`mod+r`、`mod+k`、`mod+alt+0`、`mod+0`、`f11`，自定义快捷键不再能与这些核心组合冲突。
- **配套测试**：`shortcuts-customize-modal.test.tsx` 覆盖冲突禁用。

### 2.6 全局搜索异步竞态守卫（#126）

- `GlobalSearchPanel.tsx` 引入递增 `seq` 序列号，丢弃过期请求结果，旧搜索不再覆盖新搜索。

### 2.7 源码模式导出 Word (.docx) 解绑（#127）

- `ExportMenu.tsx` 移除 `exportDocx` 上的 `blockedBySourceMode` 拦截，源码模式下可直接导出 Word（Pandoc 从磁盘读取源文档，源码内容即磁盘内容）。

### 2.8 全部替换完成提示非阻塞化（#128）

- `SearchPanel.tsx` 以面板内 `search-notice` 状态徽章替代阻塞式模态提示，不打断编辑流。

### 2.9 清空删除文件备份二次确认（#129）

- `DeletedSnapshots.tsx` 清空操作增加 `askConfirmation` 警告确认，防止误清全部恢复备份。

### 2.10 设置面板支持 Esc 键关闭（#130）

- `SettingsPanel.tsx` 增加 Escape 键监听触发 `onClose`，与快捷键帮助等其他模态保持一致的关闭习惯。

### 2.11 图片插入与上传异常反馈（#131）

- `src/components/Editor/image-upload.ts` 捕获保存/写入异常并弹出错误提示（含文件名与原因），替换静默失败。

### 2.12 自动保存冲突状态呈现（#132）

- 非交互自动保存遇到外部冲突时置 `conflictPending`，`SaveIndicator` 展示"自动保存已暂停"并可点击拉起冲突对话框，自动保存不再静默卡死。

### 2.13 多窗口 Storage 同步 E2E（#133）

- 重写 `tests/e2e/multi-window-sync.spec.ts`：同一 BrowserContext 下两个独立 Page，窗口 A 写入主题 key 触发**浏览器原生 storage 事件**，断言窗口 B 应用自动更新 DOM `data-theme`（真实应用行为，替换原恒真断言）。

### 2.14 未命名草稿内联大图体积护栏（#134）

- `image-upload.ts` 对未命名草稿粘贴/拖入超过 512KB 的内联图片输出体积警告，防止压垮配额。
