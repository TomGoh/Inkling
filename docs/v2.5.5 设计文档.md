# v2.5.5 设计文档：DOMParser 清洗器加固、全量 Dirty Tab 退出落盘与 Zoom/Pan 重渲染优化

## 1. 概述
在 v2.5.4 的基础上，根据第四轮深度 Review 的反馈，对 Mermaid SVG 安全清洗器解析机制、应用退出时的多 Tab 保存覆盖率、异常容错与重渲染视角平移策略进行了全面闭环修复与加固。

## 2. 核心修复

### 2.1 DOMParser `text/html` 模式安全解析（F1）
- **问题**：`innerHTML` 会在赋值瞬间解析并实例化活的 DOM 节点（如 `<img onerror>`/`script`），导致潜在执行窗口先于清洗属性打开。
- **方案**：使用 `new DOMParser().parseFromString(svgHtml, "text/html")` 进行完全惰性解析（不触发脚本执行与网络加载），再通过 `document.importNode` 导入宿主文档，同时保持原生 HTML 解析对 `foreignObject` / `htmlLabels` 的完全兼容。

### 2.2 退出时全量 Dirty Tab 逐项落盘（F2）
- **问题**：旧逻辑在检测到 `hasDirtyTabs` 时仅调用单次 `saveCurrent()`，后台 dirty 标签页无法得到保存尝试。
- **方案**：在 `App.tsx` 关窗拦截中，遍历所有处于 `dirty` 状态的标签页，依次通过 `switchTab(path)` 激活并 `await saveCurrent()` 执行保存；保存完毕后切回原激活标签页。

### 2.3 弹窗异常 Fail-Safe 容错与平移重置（F3）
- **弹窗容错**：`ask()` 抛出异常时采取 fail-safe 策略（中止退出），不执行 `win.destroy()`。
- **重渲染视图保护**：Mermaid 图表重新渲染时，重置平移量 `panX = 0, panY = 0` 防止图表偏出视口，同时保留用户的缩放倍数 `zoom`。

## 3. 测试与验证
- 单元测试与 E2E 测试全部通过。
- 4 处版本号同步至 `2.5.5`。
