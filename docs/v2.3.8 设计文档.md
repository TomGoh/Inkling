## 背景

## #59 外部修改保存保护（saveCurrent 基线比对）

**问题**：`useFileWatcher` 3 秒轮询有窗口期——外部修改发生在两次轮询之间（或应用失焦期间轮询结果被忽略）时，用户 Ctrl+S 会静默覆盖外部修改。v2.3.7 的冲突对话框只覆盖「轮询已感知」的场景。

**修复**（[tabs.ts](../src/store/workspace/tabs.ts)）：

- `OpenTab` 新增 `diskContent` 基线字段：记录最近一次从磁盘读取/写入的原始内容（`ensureTab` 打开时、`saveCurrent` 保存成功后、`reloadFile` 重载后更新）；
- `saveCurrent`（普通文件 + 桌面端）保存前 `readTextFile` 直读磁盘与基线比对：不一致（外部已改）则弹 `ask` 二次确认「覆盖保存将丢失外部修改」，用户拒绝则中止保存——不触发 `openingFiles` 打开态副作用；
- 磁盘读取失败（文件被删）不阻断，继续尝试保存；
- **`reloadFile`**：新增 store 方法，强制从磁盘重读并刷新 tab（`content`/`dirty: false`/`diskContent`），同步活跃镜像与分屏镜像；`openFile` 对已打开 tab 只复用缓存不重读磁盘，此前 ConflictDialog / watcher 的「重载」实际是假重载——全部替换为 `reloadFile`。

## #60 未命名草稿贴图（Data URL 内联）

**问题**：草稿 tab 的 path 是虚拟路径 `untitled-N`（非空字符串），`insertImages` 仅判空会漏掉该场景，`resolvePathFromDocument` 按 CWD 解析出错误路径，写盘报错图片插入失败。

**修复**（[image-upload.ts](../src/components/Editor/image-upload.ts)）：新增 `isUntitledPath`（空或 `untitled-` 前缀）检测；草稿场景跳过目录解析与写盘，`FileReader` 转 **Data URL 内联插入**——草稿另存到任意目录后图片随文档自带，不产生失效的相对路径。

## #61 多窗口状态同步（storage 事件）

**问题**：多窗口实例间主题、偏好设置、快捷键覆盖各自独立，一窗修改其他窗不感知（Zustand 状态与 localStorage 各自独立初始化）。

**修复**：`theme.ts` / `settings.ts` / `shortcuts.ts` 三个 store 创建时注册 `window.addEventListener("storage")`——storage 事件只在**其他**窗口修改时触发，解析 `e.newValue` 合并进本窗状态（主题同时 `applyMode` 刷 CSS 变量），天然避免自触发回环。

## #62 全局搜索点击定位（第 N 处匹配）

**问题**：点击搜索结果后光标总落到本文件**第一处**匹配（简单 `indexOf`），同文件多处命中时点第 3 条跳到第 1 处。

**修复**（[GlobalSearchPanel.tsx](../src/components/GlobalSearch/GlobalSearchPanel.tsx)）：`jumpTo` 按「点击项在本文件命中列表中的序号」定位对应的第 N 次出现——`doc.descendants` 逐文本节点累计出现次序，命中第 N 处即停（ProseMirror 中 paragraph/heading 是独立块节点，节点文本不含 `\n`，行号累计算不出目标位置）。正则模式先从命中行 preview 提取实际匹配文本再找；文本未命中（文档已编辑/正则异常）回退按顶层块序号近似行号定位。

## #63 Pandoc 临时文件并发冲突

**问题**：`pandoc_export_docx` 临时文件名固定为 `inkling-export-{pid}.md`，同进程并发两次导出互相覆盖/删除对方的临时文件。

**修复**（[pandoc.rs](../src-tauri/src/commands/pandoc.rs)）：`make_temp_export_path` 生成 `inkling-export-{pid}-{纳秒时间戳}-{原子自增序号}.md` 唯一路径，新增 Rust 单测验证连续生成的路径唯一。

## #64 asset 协议权限收敛（静态 scope + 动态放行）

**问题**：`tauri.conf.json` 的 `assetProtocol.scope` 为 `["**"]`——放行全盘任意路径，WebView 被注入时任意本地图片均可被读取，权限过大。

**修复**：

- **静态 scope 收敛**（[tauri.conf.json](../src-tauri/tauri.conf.json)）：仅保留 `$APPDATA`/`$DOCUMENT`/`$HOME`/`$TEMP` 等用户目录通配；
- **动态放行**：Rust 新增 `allow_asset_dir` 命令（校验 is_dir 后 `asset_protocol_scope().allow_directory(dir, true)` 递归放行），前端 [fs.ts](../src/lib/fs.ts) `resolveImageSrc` 解析图片绝对路径后先把所在目录加入运行时白名单（模块级 `Set` 去重避免重复 IPC，失败回退——目录恰在静态白名单内仍可加载）再 `convertFileSrc`。只放行用户实际打开的文档目录，最小权限。

## #65 嵌套列表删块误删顶级列表

**问题**：多级嵌套列表子项内点击「删除块」，`deleteCurrentBlock` 用 `$head.before(1)` 删除光标所在**顶层块**——整个顶级列表连同胞项一起被删。

**修复**（[block-commands.ts](../src/components/Editor/block-commands.ts)）：删除前沿 `$head` 祖先链找最近的 `list_item`——命中则只删当前 list_item（`$head.before(listItemDepth)`）；父列表仅剩这一项时删父列表（不留空列表）；非列表场景保持原顶层块删除逻辑。

## #67 PNG 导出离屏样式对齐

**问题**：PNG 长图导出的离屏容器把 `editor-scroll`/`milkdown` 挂在同一元素上，而 `App.css` 的排版规则全是 `.editor-scroll .milkdown ...` / `[data-theme=dark] .editor-scroll ...` **后代选择器**——同一元素挂两个类无法匹配，Callout/代码块/Mermaid/表格在导出图中丢失边框与配色；图片异步未就绪时截图留白。

**修复**（[exporter.ts](../src/lib/exporter.ts)）：离屏复刻真实编辑器**三层嵌套** `[data-theme] > .editor-scroll > .milkdown`，后代选择器全部命中，导出图与编辑器所见一致（含深色主题）；截图前等待容器内所有 `<img>` decode/load 完成（3s 超时保护）；背景色取 `.milkdown` 实际计算的 `--editor-bg`（跟随主题，透明回退白底）。
