# v2.0.0 设计文档

> 主题：UI 视觉与交互体验全面优化——建立设计令牌系统、统一图标库、现代化滚动条与聚焦环、菜单/模态动效、活跃状态视觉强化。

---

## 背景

v1.2.x 系列聚焦于功能补齐与 bug 修复，UI 样式在多个版本迭代中逐步累积，存在以下问题：

- **配色散落**：强调色在不同组件中硬编码为 `#0969da`、`#2f81f7`、`#388bfd` 等近似值，深色/浅色主题切换时部分组件漏改
- **图标不统一**：按钮图标混用 emoji（📁📄）、Unicode 符号（⋮⋮）、内联 SVG，跨平台渲染不一致、无法继承文字颜色
- **阴影生硬**：弹层使用单层 `box-shadow`，缺乏层次感
- **滚动条粗糙**：原生粗滚动条抢占视觉焦点
- **聚焦环干扰**：鼠标点击按钮也显示蓝色 `outline`，影响操作流畅度
- **缺乏动效**：菜单/模态弹出无过渡，状态切换突兀
- **活跃状态弱**：当前 tab、当前文件缺乏强视觉标识，长列表中难以定位

本次版本对全套 UI 进行系统性重构，建立可维护的设计令牌（design token）体系，统一交互语言。

## 改动清单

### 1. 设计令牌系统（CSS 变量）

[App.css](file:///workspace/src/App.css#L1-L58) 在 `:root` 与 `[data-theme="light"]` / `[data-theme="dark"]` 上集中定义语义化令牌，全组件引用变量而非硬编码色值：

| 令牌类别 | 变量 | 说明 |
|---|---|---|
| 品牌强调色 | `--accent` / `--accent-hover` / `--accent-subtle` / `--accent-fg` | 浅色 `#0969da`，深色 `#2f81f7`，统一原先散落的近似值 |
| 文字色阶 | `--text` / `--text-muted` / `--text-faint` | 三级灰阶，分别用于正文 / 次要文字 / 占位符 |
| 边框 | `--border` / `--border-strong` | 普通 / 强调边框 |
| 背景层 | `--bg-subtle` / `--bg-elevated` / `--editor-bg` / `--topbar-bg` / `--sidebar-bg` / `--outline-bg` / `--statusbar-bg` | 分层背景语义 |
| 交互态 | `--btn-bg` / `--btn-hover-bg` / `--row-hover-bg` / `--row-active-bg` | 按钮与列表行 hover/active |
| 阴影分层 | `--shadow-sm` / `--shadow-md` / `--shadow-lg` | 替代原先生硬的单层阴影，分轻/中/重三级 |
| 圆角尺度 | `--radius-sm` (4px) / `--radius-md` (6px) / `--radius-lg` (10px) | 统一圆角梯度 |
| 动效 | `--ease` (`cubic-bezier(0.2, 0, 0, 1)`) / `--duration` (`0.15s`) | 全局过渡曲线与时长 |
| 聚焦环 | `--ring` (`0 0 0 3px rgba(9, 105, 218, 0.3)`) | 键盘导航专用聚焦高亮 |
| 语义色 | `--success` / `--danger` | 保存成功 / 错误提示 |

深色主题（`[data-theme="dark"]`）使用 GitHub 风格深色配色（`#0d1117` 背景、`#e6edf3` 文字），所有令牌同步覆盖。

### 2. 统一 SVG 图标库

[icons.tsx](file:///workspace/src/components/icons.tsx) 新增统一图标组件库，替代原先混用的 emoji / Unicode 符号：

- **线性风格**：`stroke = currentColor`，随文字颜色继承，主题切换零成本
- **统一尺寸**：默认 16px，基于 24×24 viewBox，通过 `size` 属性可调
- **覆盖图标**：`IconFolder` / `IconFile` / `IconFileText` / `IconStar` / `IconStarFilled` / `IconSun` / `IconMoon` / `IconMaximize` / `IconPanelLeft` / `IconSettings` / `IconHelpCircle` / `IconX` / `IconArrowLeftRight` / `IconChevronDown` / `IconChevronRight` / `IconDownload` / `IconAlertTriangle` / `IconPalette`

顶栏按钮（禅模式 / 侧边栏 / 导出 / 主题 / 帮助 / 设置）、侧边栏头部（打开文件夹 / 打开文件）、分屏面板（交换 / 关闭）、文件树图标全部迁移至该库。

### 3. 现代化滚动条

[App.css](file:///workspace/src/App.css#L74-L94) 全局细滚动条：10px 宽、半透明滑块、透明轨道、`border: 2px solid transparent` + `background-clip: padding-box` 实现内缩视觉，hover 加深。标签页栏滚动条进一步收窄至 3px。深色主题下滑块亮度提升。

### 4. 键盘聚焦环（focus-visible）

[App.css](file:///workspace/src/App.css#L96-L103) 仅对 `:focus-visible`（Tab 键触发）显示 `--ring` 聚焦环，鼠标点击不触发蓝框，兼顾无障碍与操作流畅度。覆盖 `button` / `input` / `select` / `[tabindex]`。

### 5. 菜单与模态动效

- **菜单弹入** [App.css](file:///workspace/src/App.css#L237-L246)：`@keyframes menu-in`——轻微上移（`translateY(-4px)`）+ 缩放（`scale(0.98)`）+ 淡入，0.12s，应用于导出/主题下拉菜单、斜杠菜单、文件树右键菜单
- **空状态淡入** [App.css](file:///workspace/src/App.css#L301-L310)：`@keyframes fade-in`——上移 6px + 淡入，0.3s
- **模态遮罩淡入** [SettingsPanel.css](file:///workspace/src/components/Settings/SettingsPanel.css#L13-L20)：`@keyframes backdrop-in`——纯淡入 0.15s
- **模态弹入** [SettingsPanel.css](file:///workspace/src/components/Settings/SettingsPanel.css#L22-L31)：`@keyframes modal-in`——上浮 10px + 缩放 0.97 + 淡入，0.18s，应用于设置/快捷键帮助/快捷键自定义/全局搜索面板

### 6. Ghost 风格顶栏按钮

[App.css](file:///workspace/src/App.css#L182-L212) 顶栏按钮改为无边框 ghost 风格（VSCode / Typora 式）：透明背景、hover 灰底、active 强调色淡底，统一 28px 高、`--radius-md` 圆角。带文字标签的按钮（导出/主题）内边距略宽。

### 7. 渐变标题文字

[App.css](file:///workspace/src/App.css#L311-L324) 空状态 "InklingMD" 标题使用 `background-clip: text` + `-webkit-text-fill-color: transparent` 实现从正文色到强调色的 135° 渐变填充，强化品牌感。

### 8. 活跃 Tab 卡片样式

[TabsBar.css](file:///workspace/src/components/Tabs/TabsBar.css#L50-L78) 活跃标签页改为上浮卡片样式：
- 背景与编辑区融合（`--editor-bg`）
- `::after` 顶部 2px 强调色指示条
- `::before` 底部 1px 遮住 tabs-bar 分隔线，形成"连通"效果
- 未保存圆点使用强调色；关闭按钮默认隐藏、hover tab 时显现（防误关）

### 9. 活跃文件指示条

[Sidebar.css](file:///workspace/src/components/Sidebar/Sidebar.css#L131-L140) 文件树当前文件行：强调色淡底 + `box-shadow: inset 2px 0 0 var(--accent)` 左侧指示条 + 强调色文字与图标，长列表中一眼定位。

### 10. 现代 Toggle 开关

[SettingsPanel.css](file:///workspace/src/components/Settings/SettingsPanel.css#L120-L154) 偏好设置面板的 checkbox 改为 iOS 风格开关：34×20px 胶囊轨道 + 16px 圆形滑块，`appearance: none` 隐藏原生外观，`:checked` 时轨道变强调色 + 滑块右移 14px，`transition` 0.2s 平滑过渡，`:focus-visible` 显示聚焦环。

### 11. 模态毛玻璃遮罩

[SettingsPanel.css](file:///workspace/src/components/Settings/SettingsPanel.css#L1-L11) 模态遮罩加 `backdrop-filter: blur(2px)`，背景半透明 `rgba(31, 35, 40, 0.45)`，聚焦感更强。

### 12. 文本选择色

[App.css](file:///workspace/src/App.css#L106-L111) `::selection` 背景跟随强调色（浅色 `rgba(9, 105, 218, 0.22)`，深色 `rgba(47, 129, 247, 0.35)`），选中文字视觉与品牌统一。

### 13. 统一过渡曲线

所有交互控件（按钮、标签页、树行、菜单项、下拉框）的 `transition` 统一引用 `--ease` 与 `--duration` 令牌，保证全应用动效手感一致。

## 设计原则

1. **令牌驱动**：所有色值/阴影/圆角/动效通过 CSS 变量定义，主题切换与未来调色只需改一处
2. **语义命名**：变量按用途命名（`--bg-elevated` 而非 `--white`），深色主题覆盖时语义不变
3. **渐进增强**：动效用 `@keyframes` + CSS transition，无 JS 依赖，低性能设备自动降级
4. **无障碍优先**：`:focus-visible` 保证键盘用户可见聚焦环，同时不干扰鼠标用户
5. **克制原则**：动效时长控制在 0.12–0.3s，不过度装饰；阴影分层但不浮夸
