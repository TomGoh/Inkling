# v2.5.4 设计文档

## 概述
v2.5.4 针对 Review 反馈，修复了 Mermaid 预渲染守卫逻辑、首渲染防缩高度保护、XML DOMParser 安全解析、应用退出多 Tab 与取消保存的确认防护，并强化了 SMIL 安全规则与 LRU 单测。

## 关键变更
1. **Mermaid 预渲染与高度保护**
   - 恢复 `if (firstRenderDone || !container.isConnected || container.offsetParent === null) return;` 避免脱落容器空闲渲染导致高度被 0 覆盖。
   - 调整高度缓存覆盖顺序，优先读取 `estimateRenderHeight(value)` 作为保底高度，确保 `Math.max(height, reserved)` 真实生效。
   - 恢复 `DOMParser` 解析 `image/svg+xml`，杜绝 `innerHTML` 阶段的 XSS 执行窗口。
2. **退出落盘全矩阵保护**
   - 在 `App.tsx` 拦截关闭事件后，按序保存所有 dirty 的 Tab。
   - 若草稿取消保存或保存失败，弹出 `ask` 确认对话框，用户拒绝时阻止窗口销毁。
3. **安全与单测加固**
   - 补充 `<set>` 标签 `attributeName` 过滤及 `href` / `xlink:href` 清洗。
   - `imageSrcCache.test.ts` 补充旧缓存刷新免淘汰真实用例。
