## 任务 29：全屏 / 禅模式

### 目标
`F11` 隐藏所有 UI（侧边栏 / 大纲 / 标签页 / 状态栏 / 工具栏），纯编辑；`Esc` 退出。

### 技术方案

修改 [ui.ts](file:///workspace/src/store/ui.ts)：新增 `zenMode: boolean`，持久化到 localStorage。

```typescript
zenMode: boolean;
toggleZenMode: () => void;
setZenMode: (v: boolean) => void;
```

修改 [App.tsx](file:///workspace/src/App.tsx)：
- 全局快捷键监听 `F11`（非修饰键，直接 `e.key === "F11"`），preventDefault 后 `toggleZenMode()`
- `zenMode` 为 true 时，不渲染 Sidebar / OutlinePanel / TabsBar / StatusBar / editor-topbar，仅渲染编辑器区域
- `Esc` 在 zenMode 下退出（在编辑器内不影响 Esc 原有行为，用全局 keydown 且仅当 zenMode 时拦截）

### 验收
- F11 进入禅模式，所有 UI 隐藏，只剩编辑器
- Esc 退出禅模式，UI 恢复
- 禅模式状态重启后保留

## 任务 31：自动配对补全

### 目标
输入 `"` `(` `[` `「` 等自动配对，光标放中间；中文引号 / 书名号支持；可在设置开关。

### 技术方案

新建 `src/components/Editor/auto-pair.ts`：ProseMirror 插件，用 `handleTextInput` 拦截输入。

```typescript
export function autoPairPlugin(): Plugin
```

配对表：
```typescript
const PAIRS: Record<string, string> = {
  '"': '"',
  "'": "'",
  "(": ")",
  "[": "]",
  "{": "}",   // 可选，代码块外较少用
  "「": "」",
  "『": "』",
  "（": "）",
  "【": "】",
  "《": "》",
};
```

逻辑：
- `handleTextInput(view, from, to, text)`：若 text 是配对表的左符号
  - 若选区非空（from !== to）：用左符号 + 选中文本 + 右符号包裹
  - 否则：插入 `左+右`，光标置于中间（dispatch tr 插入两字符后 setSelection 到中间 pos）
- 跳过逻辑：若光标后已是右符号，输入右符号时只移动光标不重复插入（可选增强）
- 代码块内不触发（检查父节点是否 code_block）

修改 [settings.ts](file:///workspace/src/store/settings.ts)：新增 `autoPair: boolean`（默认 true），持久化。

修改 [Editor.tsx](file:///workspace/src/components/Editor/Editor.tsx)：
- 注入 `autoPairPlugin()`
- 监听 settings.autoPair 变化，dispatch 空 tr 触发插件重算（或通过插件 state 读取最新值）

插件内部通过 `useSettings.getState().autoPair` 实时读取，避免重建编辑器。

### 验收
- 输入 `(` 自动变成 `()` 光标在中间
- 选中文字输入 `"` 变成 `"选中文字"`
- 代码块内不触发
- 设置面板可关闭

## 任务 32：图片缩放 / 对齐

### 目标
图片节点加 width / align 属性，点击拖拽缩放，右键设置对齐（左/中/右）。

### 技术方案

修改 [image-node-view.ts](file:///workspace/src/components/Editor/image-node-view.ts)：

commonmark image schema 默认 attrs 为 `src / alt / title`。需要扩展 attrs 加 `width` 和 `align`。

由于直接改 commonmark schema 风险高，采用**自定义 image schema 覆盖**方案：

```typescript
// image-node-view.ts 内
import { imageSchema } from "@milkdown/kit/preset/commonmark";
// 用 $nodeSpec 重新定义 image，或通过 schema attrs 扩展
```

实际方案：用 prosemirror 的 `Schema` 扩展较复杂，更稳妥的是**用 NodeView 的 dom 属性承载，配合 data-attr 序列化**。但 markdown 源码需保留 width/align，标准做法是图片 alt 里写 `=widthx` 或 title 里写属性。

**简化方案**：图片 markdown 语法 `![alt](src "title")`，把 width/align 编码进 title：
- `![alt](src "width=300,align=center")`
- NodeView 解析 title 提取 width/align，渲染时应用样式
- 右键菜单 / 拖拽时更新 title

NodeView 改造：
- `dom` 用 `<div class="image-wrap">` 包裹 `<img>`，便于对齐
- 拖拽缩放：img 右下角加 `<span class="image-resize-handle">`，mousedown 拖拽计算新 width
- 右键菜单：对齐左/中/右/原始大小，调用 `view.dispatch` 更新 node attrs

### 验收
- 图片右下角拖拽可缩放
- 右键可设置对齐
- width/align 保存到 markdown title，重开恢复

## 任务 33：行内图片格式

### 目标
图片支持行内模式，插入文字流中（而非独占一行）。

### 技术方案

commonmark image schema 本身就是 `group: "inline"`，行内支持是默认行为。当前"独占一行"的观感来自 NodeView 的 dom 结构和 CSS。

修改 [image-node-view.ts](file:///workspace/src/components/Editor/image-node-view.ts)：
- 确认 schema 为 inline（commonmark 默认即 inline）
- NodeView 的 `dom` 改为 `<img>` 直接返回（不包 div），让浏览器自然行内排列
- CSS 调整 `.milkdown-image { display: inline-block; vertical-align: middle; }`

若任务 32 用了 div 包裹，需区分块级（带 align/width）和行内（无 align）两种渲染模式：当图片在段落内且前后有文字时行内渲染，否则块级渲染。简化处理：始终 inline-block，对齐通过 margin auto 在块级上下文生效。

### 验收
- 在段落文字间插入图片，图片在文字流中显示
- 图片与文字基线对齐合理

## 任务 34：表格列宽拖拽

### 目标
拖拽表格列边界调整宽度，宽度信息持久化。

### 技术方案

[Editor.tsx](file:///workspace/src/components/Editor/Editor.tsx) 已引入 `columnResizingPlugin`，拖拽功能本身已可用。

**持久化问题**：prosemirror-tables 把列宽存在 table 节点的 `columnWidths` 属性（通过 `tr.setNodeAttribute`），这是文档内持久化。但 Milkdown 的 markdown 序列化不保留 table 的自定义属性，导出/重开会丢失列宽。

**结论**：markdown 标准不携带列宽信息，无法真正持久化。本任务实际只需：
1. 确认 `columnResizingPlugin` 已生效（已引入）
2. 验证拖拽功能可用
3. 列宽在当前编辑会话内有效，文档属性更新

若需跨会话保留，需把列宽存到外部（如 `.inkling/table-widths.json`），成本高且非标，本版不做。

### 验收
- 拖拽表格列边界可调整宽度
- 当次编辑会话内列宽保持

按依赖关系和独立性排序：

1. **任务 29（禅模式）** — 独立，简单
2. **任务 30（文件夹折叠记忆）** — 独立，简单
