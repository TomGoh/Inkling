# v2.3.3 设计文档

> 主题：大文档窗口抖动修复 + 引用块区域滚动掉帧根治（渲染缓存 / 高度预留 / 大纲采样重构）。

---

## 背景

v2.3.2 修复了图表滚动掉帧的主体（空闲预渲染），用户实测仍反馈两个问题：

1. **打开大文件后窗口一直抖动**；
2. **引用块区域滚动仍明显掉帧**，v2.1.0 丝滑、v2.3.2 掉帧。

## 定位过程

### 问题一：窗口抖动 —— 视口上方图表后台渲染触发滚动锚定补偿

空闲预渲染逐张渲染视口外的图表，占位容器（min-height 40px）渲染后变为实际高度（数百 px）。**整体位于视口上方**的图表变高时，浏览器滚动锚定（scroll anchoring）为保持可见内容稳定反复补偿 scrollTop——每补偿一次产生一次可见跳动；空闲队列逐张出队，跳动以约 250ms 间隔持续数秒，表现为"窗口一直抖动"。视口下方的图表变高不影响可见内容（锚点不移动），故刚打开（滚动在顶部）时不抖，**滚动一段后再等预渲染推进才抖**。

### 问题二：引用块掉帧 —— posAtCoords 采样单次 55-67ms

PerformanceObserver longtask 监测引用块密集区（371 个 blockquote 中 196 个集中在 200k-250k px 段）脚本滚动：

- 3 秒内 6 个长任务，每个 **55-67ms**，间隔精确吻合"120ms 采样节流 + ~60ms 采样耗时"≈183ms 周期；
- 页面静置时 **0 长任务**，排除定时器/后台噪声；
- 该区域附近无图表、无 CodeMirror 懒挂载，排除 v2.3.2 已知的代码块因素。

真凶是 v2.2.0 大纲自动跟随引入的滚动采样：`posAtCoords` 在 ProseMirror 内部需要**线性扫描文档级子节点的 rect** 定位坐标对应位置——万行文档约 1.8 万个块级子节点，单次采样 50ms+。v2.2 定位时测的纯文本区恰好命中快速路径未暴露；引用块（深层嵌套 blockquote）采样命中慢路径。**v2.1.0 没有大纲面板，滚动路径无任何 JS 采样**，故丝滑。

另一加重因素：压测文档 60 张图表仅 **8 种源码**（同一图表粘贴多处），v2.3.2 对每张都做 ~150ms 全量 parse/layout——打开后 ~9 秒的预渲染风暴期间任何滚轮操作都可能撞上 150ms 任务。

## 修复设计

### 1. Mermaid 渲染结果缓存（mermaid-view.ts）

模块级 `Map<source, {svg, height}>` LRU 缓存（上限 32 条）：

- `render()` 命中缓存直接注入 SVG 字符串，跳过 `mermaid.render`（重复图表从 ~150ms 降至 ~2ms）；
- 渲染后实测 `offsetHeight` 写回缓存并锁定本实例 `min-height`。

### 2. 占位高度预留（mermaid-view.ts）

NodeView 创建时即按缓存高度（未见过源码按行数粗估）设置 `diagram.min-height`：

- 重复图表创建即预留**精确高度**，占位 → 渲染高度跳变为 0，后台预渲染不再引起布局位移（实测打开全程 scrollHeight 稳定，CLS 0.00）。

### 3. 空闲队列跳过视口上方（mermaid-view.ts）

队列任务执行时检查 `container.getBoundingClientRect().bottom < 0`（整体在视口上方）则跳过，交给视口路径（300px 预载边距）滚回时再渲染——上方布局不再变化，滚动锚定补偿随之消失。缓存使命中图表即时渲染，滚回上方也几乎无开销。

### 4. 大纲滚动采样重构（outline-tracker.ts）

彻底移除滚动路径的 `posAtCoords`：

- **位置缓存**：`nodeDOM(heading.pos)` 批量读取各标题元素在滚动坐标系中的位置（同帧批量读取只触发一次布局），滚动采样退化为 `scrollTop` 与缓存数组的**二分比较**（微秒级）；
- **失效重建**：文档变更防抖后重建；采样时检测滚动总高/宽度变化（图表渲染、窗口缩放、布局列切换）自动重建；
- **节流 120ms + 尾随采样**：滚动中限频，停止后收敛到当前章节。

## 验证数据（生产构建压测文档：1.8 万行 / 398KB / 60 图表（8 种源码）/ 371 引用块）

| 场景 | v2.3.2 | v2.3.3 |
|---|---|---|
| 打开后空闲预渲染 60 张 | ~9s（60 次全量渲染） | **≤5s（8 次真实渲染 + 52 次缓存命中）** |
| 打开至预渲染完成 scrollHeight | 随每张渲染持续变化 | **全程稳定 347,115px（CLS 0.00）** |
| 引用块密集区滚动（200k→225k px，80px/帧） | 94fps，15 帧 >34ms，6 个 55-67ms 长任务 | **105fps，2 帧 >34ms，0 长任务，p95 35→25ms** |
| 向上滚动（346k→303k px，120px/帧） | — | **119fps，0 帧 >34ms，p95 11ms** |
| 静置后 scrollTop 漂移（抖动） | 持续跳动 | **稳定不变** |
| 大纲当前章节跟踪 | posAtCoords 每次采样 55-67ms | 二分比较微秒级，高亮按位置正确更新 |
