## 1. 背景与目标

v2.7.0 中模式切换滚动采用 `mapScrollTop` **比例映射**方案（#121）。该方案在普通文档上表现良好，但在**内容密度不均**的文档（如表格、代码块、图片密集）里，比例映射会因两端内容高度占比不一致而**偏出当前区块**：读者明明停在"第 5 节"，切换后视口顶部却落在"第 4 节的表格"上。

Issue #136 的目标：把模式切换的恢复从"滚动高度比例"升级为"**内容锚点**"驱动——即在富文本侧记录**视口顶部那一行内容**，切到源码后在 CodeMirror 里把同一段内容滚到视口顶部，密度不均也不丢阅读位置。

本版本统一了竞争方案 #137（自研）与 #138（外部作者）的优势，并吸收 #137 附带修复，经两轮评审（B1 + N1~N8）打磨后交付。

## 2. 核心方案与技术设计

### 2.1 内容锚点映射（#136 主方案）

- **进入方向（WYSIWYG → CM）双候选锚点**：富文本侧采集两类锚点位置：
  - `topPos`：视口顶部块在 PM doc 中的 position；
  - `anchorOffset`：把 `topPos` 换算成 Markdown 偏移（内容锚点）。
  - **code_block 吸附**：当视口顶部块是代码块时吸附到块起始，避免进入 CM 后因代码块解析浮动而漂移。
- **退出方向（CM → WYSIWYG）精确文本匹配**：新增 `resolveAnchorProsePos`，取锚点行的纯文本形态，在 PM doc 全文文本里定位（重复行取与权重估计最近的一处），再二分找出覆盖该文本索引的最小 PM pos；锚点行命不中时向下/向上最多收集 8 条候选行逐一尝试（标记密集行剥标记后常可命中）；全部失败退回权重比例法。行归一化复用 `source-mode-cursor` 的 `markdownNormLine`，消除双实现漂移（评审 N3）。
- **视口顶部块定位**：`blockStartAtTop` 对顶层块起始位置二分 `coordsAtPos`，找出真正压在视口顶的块。

### 2.2 单一写者原则（useCursorStateRestore）

- 引入 `useCursorStateRestore`，在模式翻转帧显式跳过自身恢复，避免"退出恢复"与"滚动持续缓存"双写者竞态。

### 2.3 settle 收敛循环

- 处理 CM 首帧高度估算问题：逐帧重算滚动位置直至收敛，规避首帧高度未定型导致的跳变。

### 2.4 滚动热路径性能（评审 B1）

- `Editor.tsx` 滚动路径 `cacheTopPos` 加 **rAF 合帧** + `flushWysiwygTopPosRef`（读取锚点前同步 flush 待执行帧），规避快速滚动后立即切换的滞后一帧漂移。滚动热路径**绝不同步跑 `posAtCoords`**，与 outline-tracker v2.3.3 教训一致。

### 2.5 附带修复（移植 #137）

- **源码模式 CM 补 `defaultKeymap`**：`Ctrl+Home/End`、方向键、词移动等标准导航键此前全部无效，已补齐，保留应用级自定义覆盖（源码模式冲突黑名单）。
- **菜单文案统一**：更多菜单「专注模式（禅模式）」统一为「禅模式」，避免与设置面板独立的「专注模式」混淆。

### 2.6 评审 N1~N8 落地

- **N1**：退出方向 3 单测改经 `exitSnapshotRef`（`onUnmountSnapshot` 真实路径）注入，不再 mock 生产不可达分支；`liveCmScroll` 注释标注纯兜底。
- **N2**：修正 `codemirror-shared` 对 defaultKeymap 中 Ctrl-n 仅 mac 变体的注释。
- **N3**：提取通用 `markdownNormLine`，删除本地 `markdownLineToPmText` 重复实现。
- **N4**：`UI-UX-REVIEW.md` 迁移至 `tests/fixtures/`，同步 spec 引用路径。
- **N5**：恢复 `tsconfig` 对 `tests/e2e` 的类型检查（补 `@types/node`）。
- **N6**：新增 `tests/e2e/helpers.ts` 的 `waitScrollConverged`，以 scrollTop + scrollHeight 收敛轮询替换 E2E 固定 sleep。
- **N7**：退出光标语义偏移 = 视口锚点优先（设计意图，于 PR body 留档）。
- **N8**：源码模式冲突检测对等于快捷键自身默认值的绑定放行（允许还原默认键，如 `mod+f`）。

### 2.7 回归 E2E 锚点漂移 flaky 根因修复

- 数据采样定位：**非锚定逻辑缺陷**。`scrollIntoView` 已把目标标题滚到视口顶，但退出源码模式 remount 的**异步滚动恢复（rAF）**把 scrollTop 从目标标题拉回上一节，进入源码时视口顶部实为上一节，锚点忠实落在上一节——测试驱动滚动被 remount 恢复竞态覆盖。
- `scrollHeadingToTop` 改为「滚动 → 等收敛 → 校验标题贴视口顶（gap∈[-2,8]），不达标重滚，最多 5 次」。
