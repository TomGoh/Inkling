## 一、生产代码 bug 修复

### 1. 自动配对补全崩溃（auto-pair.ts）

**现象**：在空段落输入任意配对符号（`(` `[` `{` `「` 等）时，编辑器直接崩溃白屏，报错：
```
RangeError: Selection passed to setSelection must point at the current document
```

**根因**：`handleTextInput` 的无选区分支先 `tr.insertText(text + right, from)` 修改了 transaction 文档，随后用 `view.state.doc.resolve(from + 1)` 创建 Selection——`view.state.doc` 是旧文档，插入两字符后 `from + 1` 在旧文档中的位置语义已变，Selection 指向旧文档触发 ProseMirror 不变式校验抛错。

**修复**：`view.state.doc.resolve` → `tr.doc.resolve`，用 transaction 的新文档 resolve 位置。

```typescript
// 修复前
tr.setSelection(TextSelection.near(view.state.doc.resolve(from + 1), -1));
// 修复后
tr.setSelection(TextSelection.near(tr.doc.resolve(from + 1), -1));
```

> 注：选区包裹分支（`from !== to`）原本就用 `tr.doc`，无此 bug。仅无选区分支遗漏。

### 2. Callout 解析器不兼容 Obsidian 常见写法（callout.ts）

**现象**：标准 Obsidian callout 语法
```
> [!NOTE]
> 内容
```
不渲染为提示框，显示为普通引用块（文字 `[!NOTE] 内容` 原样可见）。

**根因**：`remarkCalloutTransformer` 用 `/^\[!(\w+)\]$/` 要求首段文本**完全等于** `[!TYPE]`。但 `> [!NOTE]\n> 内容` 在 markdown AST 中是一个段落（soft break 连接两行），首段文本为 `[!NOTE]\n内容`，不匹配。

仅 `[!TYPE]` 独占首段（序列化往返格式 `> [!NOTE]\n>\n> 内容`）才能识别。

**修复**：正则改为 `/^\[!(\w+)\]/`（首段**以** `[!TYPE]` **开头**即匹配），`[!TYPE]` 之后的剩余文本作为 callout 内容保留为首个子段落。兼容两种写法：

1. `[!TYPE]` 独占首段（序列化往返格式）
2. `[!TYPE]` 后紧跟内容（Obsidian 常见写法）

### 3. Front Matter 节点视图缺少 data-value 属性（frontmatter.ts）

**现象**：`.frontmatter-block` 元素无 `data-value` 属性（返回 null）。

**根因**：`toDOM` spec 声明了 `data-value`，但 NodeView 自建 `dom` 时只设了 `data-frontmatter`，漏设 `data-value`。NodeView 的 `dom` 覆盖 `toDOM`，导致属性缺失。

**修复**：NodeView 创建 `dom` 时同步设 `data-value`，`update` 回调中同步更新。

## 二、E2E 测试补全

新增 8 个测试文件、67 个测试用例，覆盖此前无 E2E 的功能模块：

| 文件 | 用例数 | 覆盖功能 |
|------|--------|----------|
| `auto-pair.spec.ts` | 6 | 括号/引号自动配对、Backspace 删双、选区包裹 |
| `callout.spec.ts` | 5 | NOTE/WARNING/TIP 渲染、图标、头部不可编辑 |
| `editor-modes.spec.ts` | 3 | 专注模式开关、focus-mode 类、当前块高亮 |
| `frontmatter.spec.ts` | 4 | YAML 块渲染、标签、CodeMirror、文档顶部位置 |
| `link-follow.spec.ts` | 2 | 外部链接 window.open、锚点跳转 |
| `math.spec.ts` | 4 | 行内/块级公式 KaTeX 渲染、段落内位置 |
| `shortcuts-customize.spec.ts` | 6 | 自定义面板、捕获组合键、冲突检测、遮罩关闭、恢复默认 |
| `toc.spec.ts` | 4 | TOC 块渲染、目录项、点击跳转、层级缩进 |

同时修复了既有 E2E 的多处 flaky 问题：
- `export.spec.ts` E6：用 `page.once("dialog")` 自动 accept alert，解决同步阻塞死锁
- `file-tree-context.spec.ts`：用祖先选择器区分树节点与书签/最近打开条目
- `outline.spec.ts` O2：用 `outline-demo.md` 静态文件替代动态输入标题
- `slash-menu.spec.ts` S5：Escape 时删除触发字符 `/`，防止菜单关了又弹

测试基础设施增强：
- `helpers.ts`：提取 `openMockWorkspace`/`openFile`/`appendToEditor`/`MOD` 共享辅助
- `fs.ts` mock：新增 `findNode`/`findParent`/`rebasePath`/`splitPath` 让浏览器端 rename/delete/create 同步更新目录树；新增 5 个 mock 示例文件（frontmatter/math/callout/toc/link-demo）
