## 任务 41：修复合并 PR #8 后的构建失败

### 问题
朋友 PR 给 `EditorProps` 新增 `filePath` 属性（用于 `imageUploadPlugin`/`imageView` 解析本地图片相对路径）。合并冲突时遗漏：
- [Editor.tsx](file:///workspace/src/components/Editor/Editor.tsx) 的 `EditorInner` / `MarkdownEditor` 两个函数解构未加 `filePath` → `TS2304: Cannot find name 'filePath'`
- `<EditorInner>` 调用未传 `filePath` → `TS2741: Property 'filePath' is missing`

### 修复
- 两个函数解构补 `filePath`，`<EditorInner>` 调用补传 `filePath`。
- **额外修复隐患**：[App.tsx](file:///workspace/src/App.tsx) 三处 `MarkdownEditor` 调用补 `key={currentFile}` / `key={splitFile}`。Editor.tsx 注释明确「filePath 变化由外层 key 触发重建」，否则切换文件后图片路径插件闭包仍用旧值，PR #8 失效。

### 验证
- `npx tsc --noEmit` 通过，3 个 TS 错误消除
- CI run 30643880571 `success`

## 任务 42：中文句号字形修复（issue #9）

### 问题
Linux 下中文句号 `。`（U+3002）显示在字符方框中部（日文 CJK JP 字形），而非简体中文的左下位置。

### 根因（issue #9 已分析）
- [index.html](file:///workspace/index.html) `lang="en"`，Fontconfig 对 `sans-serif:lang=en` 的 U+3002 回退到 `Noto Sans CJK JP`
- [App.css](file:///workspace/src/App.css) 全局字体栈只有西文字体 + `sans-serif`，未指定简体中文字体

### 修复（按 issue 建议）
- `index.html`：`lang="en"` → `lang="zh-CN"`
- `App.css` 全局字体栈追加 `"Noto Sans CJK SC", "Microsoft YaHei", "PingFang SC"`

### 验收
- Linux 下中文句号回到左下角简体字形
- Windows/macOS/Linux 中英文混排正常，浅深主题一致
- 英文/数字/代码块不受影响（等宽字体栈未动）

## 任务 45：品牌重命名 Inkling → InklingMD

### 目标
规避与 Inkling Systems 公司商标混淆，更名为 InklingMD。

### 改动范围
**用户可见品牌名（必改）**：
- [tauri.conf.json](file:///workspace/src-tauri/tauri.conf.json)：`productName` / 窗口 `title` / `identifier`（`com.inklingmd.editor`）
- [index.html](file:///workspace/index.html)：`<title>`
- [README.md](file:///workspace/README.md)：标题 + badge URL
- [CONTRIBUTING.md](file:///workspace/CONTRIBUTING.md) + issue/PR 模板：品牌名与仓库 URL
- 源码 UI 文案：[main.tsx](file:///workspace/src/main.tsx) 崩溃页、[App.tsx](file:///workspace/src/App.tsx) 空状态、[fs.ts](file:///workspace/src/lib/fs.ts) mock 内容、[newWindow.ts](file:///workspace/src/lib/newWindow.ts) 默认标题

**构建产物名（必改）**：
- [Cargo.toml](file:///workspace/src-tauri/Cargo.toml) / [Cargo.lock](file:///workspace/src-tauri/Cargo.lock) / [main.rs](file:///workspace/src-tauri/src/main.rs)：包名 `inkling` → `inklingmd`，lib 名 `inkling_lib` → `inklingmd_lib`
- [build-windows.yml](file:///workspace/.github/workflows/build-windows.yml)：产物 `Inkling.exe` → `InklingMD.exe` 等

**故意不改（内部技术标识符，改了丢用户数据）**：
- localStorage key（`inkling-theme` / `inkling-ui` / `inkling-shortcuts` / `inkling-settings` / `inkling-recent-files` / `inkling-collapsed-dirs` / `inkling-bookmarks`）—— 改了用户主题/折叠/书签/快捷键全丢
- ProseMirror `PluginKey`（`inkling-block-drag` / `inkling-outline-tracker` 等）—— 纯内部命名，用户不可见
- CSS class（`.inkling-block-handle` 等）—— 改了要同步改 ts 引用，只有风险没收益
- 自定义事件名 / window label 前缀

### 验证
- 前端 `pnpm build` 通过
- CI run 30645469039（含 Cargo.toml 包名改动）`success`，Rust 编译通过
- GitHub 仓库 Rename 为 `zhkp/InklingMD`，旧 URL 301 跳转
