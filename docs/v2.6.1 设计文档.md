# InklingMD v2.6.1 架构加固、缺陷修复与测试质量重构设计文档

## 1. 概述与设计背景
InklingMD v2.6.1 基于 WorkBuddy Code Review 审查报告中指出的所有 P0（致命安全与死锁）、P1（稳定性与性能优化）、P2（工程治理与文档真实性）问题进行了彻底的架构加固、缺陷修复与测试重构。本版本旨在消除深层次的并发死锁隐患、提升极端场景下的数据安全与防御纵深，并建立 100% 真实有效、高覆盖率的测试保障体系。

## 2. P0 级严重缺陷修复与架构决策

### 2.1 修复 #91 保存死锁漏洞
- **问题根因**：在 `src/store/workspace/tabs.ts` 中，`isUntitled` 分支的动态插件加载 `await import("@tauri-apps/plugin-dialog")` 与 `await save(...)` 位于 `try` 块之外。当在无界面环境或插件调用抛出异常时，外层 `saving: true` 无法进入 `finally` 释放，导致全局保存功能永久死锁。
- **架构决策与修复**：将对话框插件加载和另存为路径选择逻辑完全移入 `try` 块内部，确保无论用户取消、插件异常还是写盘失败，`finally` 块均无条件执行 `set({ saving: false })` 释放互斥锁。

### 2.2 修复 #100 / #91 冲突弹窗异常吞咽导致数据静默覆盖
- **问题根因**：在保存冲突检测中，调用 `ask` 弹窗询问用户是否覆盖。原代码通过空 `catch` 吞咽了弹窗抛出的异常或取消操作，随后流程未中断，直接继续执行写盘覆盖操作，造成意外数据丢失。
- **架构决策与修复**：对冲突弹窗交互进行严谨的布尔与异常控制，当用户选择取消或弹窗异常时，明确将操作视为放弃覆盖，立即安全退出并将 `saving` 释放为 `false`。

### 2.3 修复 #86 CSS 16进制转义注入与 SVG 协议检查
- **问题根因**：原 HTML 视图清理采用简单的 `url(`、`image(` 字符串过滤，攻击者可通过 CSS Unicode/16 进制转义（例如 `u\72 l(//evil.com/t.gif)`）以及 SVG `<use xlink:href="...">` 绕过检查发起外联探测或脚本注入。
- **架构决策与修复**：
  1. 实现 `unescapeCss` 函数，先清除 CSS 注释再解析 1~6 位十六进制转义与字符转义，转义还原后再进行危险关键字匹配与清理；
  2. 针对 SVG 命名空间属性 `xlink:href`，同步接入 `isSafeUrl` 协议白名单检查，拦截 `javascript:` 和非图片 `data:` URI。

### 2.4 修复 #111 CSP 策略与 Asset 权限收紧
- **安全加固**：
  1. 在 `src-tauri/tauri.conf.json` 中配置严格的 CSP 策略：`default-src 'self'; img-src 'self' https: data: asset:; style-src 'self' 'unsafe-inline';`；
  2. 收紧 `assetProtocol` 静态访问范围（scope）至应用核心数据目录（`$APPDATA/**`, `$APPLOCALDATA/**`, `$DATA/**`, `$TEMP/**`），移除非必要的全盘符广义权限。

### 2.5 修复 #113 隔离 Mock 数据防止进生产包
- **问题根因**：原 `src/lib/fs.ts` 中直接静态导入 `mockFs` 模块，导致无用的浏览器 Mock 数据被无条件打包进生产构建包。
- **架构决策与修复**：将静态导入改为在浏览器降级分支中按需动态 `await import("./mockFs")`，实现生产包摇树优化与零 Mock 污染。

## 3. P1 级架构与稳定性优化

### 3.1 #100 自动保存指数退避与非阻塞模式
- **自动保存退避**：在 `src/lib/useAutoSave.ts` 中引入失败计数器与指数退避算法（2s ➔ 4s ➔ 8s ➔ 16s ... 最长 60s），保存成功后自动重置，避免在磁盘满或文件无权限时造成频繁无效 I/O 与性能雪崩。
- **非阻塞模式**：`saveCurrent` 增加 `{ interactive?: boolean }` 参数（默认 `true`）。自动保存调用时传入 `interactive: false`，遇到外部文件变更冲突时静默跳过，绝不弹出阻塞对话框打断用户正常输入。

### 3.2 #89 Rust 原子写盘物理落盘 (fsync) 与 Pandoc 异步化
- **物理落盘**：`src-tauri/src/commands/mod.rs` 在将内容写入临时文件后，显式调用 `file.sync_all()` 强制操作系统将缓冲区物理刷盘，然后再执行原子 `rename` 覆盖，彻底避免断电或崩溃导致的数据截断。
- **线程池卸载**：`src-tauri/src/commands/pandoc.rs` 将 `pandoc_check` 与 `pandoc_export_docx` 改为 `async fn` 并使用 `tokio::task::spawn_blocking` 将同步命令行执行卸载至独立阻塞线程池，防止长时间运行阻塞 Tauri 主事件循环。

### 3.3 #92 saveError 错误状态隔离
- 保存发生异常时，仅当当前处于活跃的 Tab 路径与触发保存的 Tab 路径一致时才设置顶层 `saveError`，杜绝用户在多 Tab 间切换时出现的报错提示漂移。

### 3.4 #93 文件删除内存保护暂存
- 当工作区外部或菜单删除文件且该文件存在未保存的修改（`dirty: true`）时，在 `localStorage` 备份区（`inkling_deleted_snapshot`）自动写入临时快照，保障意外删除后的数据可恢复性。

### 3.5 #98 修复 fileRequests 泄漏
- 在 `src/store/workspace/fileTree.ts` 的 `onFileRenamed` 事件中，对 `fileRequests` Map 缓存中的 Promise 键值进行同步迁移，避免并发请求悬空与内存泄漏。

### 3.6 #96 useFileWatcher 监听容差精度优化
- 外部修改监听的防抖时间容差精度从 1 秒优化至毫秒级（0.001s），提升冲突检测的敏锐度与准确性。

### 3.7 #97 Store 校验与死 mock 清理
- `src/store/ui.ts` 与 `src/store/shortcuts.ts` 增加逐字段防御性校验与非法数据降级；
- 清理测试中失效的 mock 引用（`resolveAssetUrl` ➔ `resolveImageSrc`）。

### 3.8 #108 右键菜单边界钳制与闪烁消除
- `image-node-view.ts` 接入 `clampMenuPosition` 视口防溢出算法；
- `useContextMenuClamping` 钩子从 `useEffect` 升级为 `useLayoutEffect`，在浏览器绘制前完成几何计算，彻底消除弹出位置跳动与闪烁。
