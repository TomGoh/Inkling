# InklingMD v2.6.0 设计文档

## 1. 背景与目标
根据 `UI-UX-REVIEW.md` 深度审查评估报告，对 InklingMD 的整体 UI/UX 系统进行现代化、系统化的重构升级：
1. **Design Tokens 系统建立**：收敛全项目杂乱的颜色、字号与间距魔法数，建立包含色彩阶梯、字体栈、间距、圆角、阴影、层级和过渡动画的标准 CSS 变量系统；
2. **块工具栏（BlockToolbar / TableToolbar）架构重构**：由多行折叠重构为 32px 单行 Command Bar，常用格式常驻，低频操作收纳至 `+ 插入 ▾`，并全面实现 SVG 矢量图标化；
3. **App Shell 与布局层级优化**：明确 Canvas / Surface / Elevated 三层表面阶梯，优化侧边栏、分屏分隔线与顶栏接缝；
4. **Markdown 渲染与排版提升**：H1/H2 移除底边框线，依托字号阶梯与垂直节奏排版，正文行高统一为 1.75，版心 800px 居中自适应，代码块默认主题融入画布；
5. **通用对话框与无障碍提升**：统一毛玻璃遮罩、12px 圆角与 Focus Ring，模态窗全量支持 ARIA 属性与 Esc 关闭。

## 2. 详细设计与实现方案

### 2.1 Design Tokens 系统 (`src/App.css`)
- **色彩与层级**：`:root` 与 `[data-theme="dark"]` 分别定义 `--bg-canvas`、`--bg-surface`、`--bg-subtle`、`--bg-elevated`，以及文本、边框与强调色；
- **空间刻度**：定义 `--space-1: 2px` 至 `--space-8: 32px`；高度规范 `--height-sm: 28px`、`--height-md: 32px`、`--height-lg: 40px`；
- **圆角与阴影**：`--radius-xs` 至 `--radius-xl`，分层 `--shadow-sm`、`--shadow-md`、`--shadow-lg`；
- **Z-Index 语义分层**：定义 `--z-elevated: 1`、`--z-sticky: 10`、`--z-dropdown: 100`、`--z-popover: 200`、`--z-modal: 1000`。

### 2.2 工具栏与组件交互优化
- **TableToolbar**：规范为单行紧凑布局（`flex-wrap: nowrap`），表格增删行列与对齐仅在表格内聚焦时显示；新增 `IconColumns`、`IconRows`、`IconTrash`、`IconPalette` 等 SVG 矢量图标；
- **Sidebar & Outline**：侧边栏头部新增快捷新建 `+` 按钮；大纲项高度统一为 28px，增加高亮指示条与单行截断；
- **Empty State**：去除彩虹渐变字，重构为极简现代化排版并提供「打开文件夹」与「打开文件」操作按钮；
- **Editor Modes & A11y**：常态编辑模式当前块挂载 `.inkling-current-block` 弱指示线；代码块默认主题为 `"none"`；设置与搜索等弹窗添加 `role="dialog"` 与 `aria-modal="true"`，支持 Esc 快捷退出；支持 `prefers-reduced-motion: reduce`。

### 2.3 测试与防御策略
- 新增 `tests/unit/design-system-tokens.test.ts`，验证核心 Design Tokens 变量定义完整性。

## 3. 验证与影响分析
- 46 个测试套件，429 个测试全部 100% 通过；
- 前端 TypeScript 编译与 Vite 构建零报错；
- 纯 UI/UX 体验重构，对原有 Markdown 解析、文件 I/O 与快捷键业务逻辑无破坏性改动。
