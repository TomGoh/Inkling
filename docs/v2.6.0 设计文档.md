# InklingMD v2.6.0 设计与架构加固文档

## 1. 概述与设计背景
InklingMD v2.6.0 是一次聚焦于**数据安全、并发防护、代码架构治理与深度可靠性**的里程碑版本。本版本全面排查并彻底闭环了 GitHub 社区提交的 32 项 Issues（#85 ~ #116），涵盖数据写盘、多标签隔离、安全过滤、异步并发与工程规范等核心领域。

---

## 2. 核心问题根因分析与架构决策

### 2.1 数据安全与保存链路（#85, #89, #91, #92, #93, #100, #102）
- **原子写盘防截断（#89）**：原 write_text_file 直接在目标路径打开文件覆盖写入，若在写盘中间发生断电或崩溃，可能导致文件内容截断损坏。本版本在 Rust 后端实现 save_file_atomic，先写入同目录下的临时文件并同步刷盘，最后通过原子重命名（Atomic Rename）覆盖目标文件，确保写盘的强一致性与容灾能力。
- **并发编辑脏标记保护（#85）**：原逻辑在保存开始与结束之间产生的新输入，会在保存完成后被盲目清除 dirty 状态。现改为记录发起保存时的内容快照基线，仅当当前内容仍与保存快照一致时才清除 dirty 标记。
- **保存状态互斥与多 Tab 回写隔离（#91, #92）**：保存前立即置位 saving = true 防止自动保存与手动保存重入；多 Tab 并发操作下回写结果精确绑定 tab.path，消除跨标签页串写。
- **外部删除安全确认与自动保存退避（#93, #100）**：当带未保存修改的文件在外部被删除时，弹出确认对话框保护用户数据；自动保存失败时采取指数退避并提供静默状态栏指示。

### 2.2 交互与编辑体验（#94, #95, #98, #99, #103）
- **导出与复制强同步 Flush（#94）**：在导出 HTML、PDF、PNG、Docx 或复制 Markdown/富文本时，统一主动调用 flushAllMarkdownPublishers 强制清空防抖队列，确保导出结果始终为编辑器当前最新 DOM 状态。
- **斜杠菜单精准取消（#95）**：Esc 关闭斜杠菜单时，精准计算关键字长度与斜杠位置进行删除，避免误删上下文正常字符。
- **文件重命名状态原子迁移（#98）**：重命名触发时，原子化同步迁移 openTabs、activeTabPath、bookmarks、expandedDirs 以及光标/滚动映射。
- **右键菜单视口边缘防溢出（#108）**：封装 useContextMenuClamping hook 与 clampMenuPosition 算法，在右键菜单靠近窗口右侧或底部时自动翻转/钳制在安全区域内。

### 2.3 安全与防护体系（#86, #87, #96, #111）
- **DOMPurify 白名单安全收紧（#86）**：彻底移除 style 标签的直接嵌入权限，并在 CSS 属性过滤中拦截 @import、url() 和 image()，阻断恶意 CSS 注入与外联追踪信标探测。
- **安全重载与异常捕获（#87）**：reloadFile 增加全链路 try/catch 兜底与全局通知，杜绝未捕获的 Unhandled Rejection 异常导致白屏。
- **工作区搜索目录过滤与符号链接环路保护（#90）**：Rust 搜索和前端索引深度遍历时，自动跳过 node_modules、.git、target 等依赖目录，并利用已访问节点集合防范 symlink 死循环。

### 2.4 算法优化与工程规范（#105, #113, #114, #115, #116）
- **Diff 算法空间优化（#105）**：优化 LCS diff 算法为空间复杂度 O(N) 的滚动数组实现，大文本对比时内存占用大幅降低。
- **模块抽象与解耦（#113, #114, #115）**：
  - 提取统一的 path-utils.ts（跨平台斜杠与 Windows 盘符标准化处理）；
  - 提取统一的 storage.ts（安全的 loadJSON / writeJSON 异常捕获与回退）；
  - 将浏览器端 Mock 逻辑从核心 fs.ts 彻底剥离至独立 fs-mock.ts。
- **测试工程健全（#116）**：补齐所有测试文件的 TypeScript 类型定义，单测与集成测试用例扩充至 470+。
