# v1.2.10 设计文档

> 主题：修复全部替换点击后报错 `command plugin: dialog|message not allowed acl`。

---

## 背景

用户反馈：v1.2.9 修复后，点击"全部替换"仍报错 `command plugin: dialog|message not allowed acl`。

v1.2.9 修复的是 `write_text_file`（自动保存链路）的 ACL 权限，但本次报错来自另一个被拦截的 invoke：dialog 插件的 `message` command。

## 根因

[SearchPanel.tsx:114](file:///workspace/src/components/Editor/SearchPanel.tsx#L114) 在全部替换成功后调用浏览器原生 `alert()`：

```typescript
if (n > 0) alert(`已替换 ${n} 处`);
```

Tauri v2 的 webview 会**自动拦截** `window.alert()` 并映射到 dialog 插件的 `dialog.message` command，`window.confirm()` 映射到 `dialog.ask`。

[capabilities/default.json](file:///workspace/src-tauri/capabilities/default.json) 只授权了 `dialog:allow-open` 和 `dialog:allow-save`，缺少 `dialog:allow-message` 和 `dialog:allow-ask`，于是 `alert()` 触发的 `dialog.message` invoke 被 ACL 拦截 → `command plugin: dialog|message not allowed acl`。

### 影响范围

全项目共 **20 处** `alert()`/`confirm()` 调用（SearchPanel、App、TabsBar、TabContextMenu、Sidebar、useFileWatcher、theme、exporter），全部会触发同样的 ACL 错误。用户在"全部替换"上报只是因为该场景最先触发。

## 修复

[capabilities/default.json](file:///workspace/src-tauri/capabilities/default.json) 补充 dialog 插件的 message 和 ask 权限：

```json
"dialog:allow-open",
"dialog:allow-save",
"dialog:allow-message",
"dialog:allow-ask",
```

dialog 插件的 command 与权限标识符对应关系：

| 浏览器 API | dialog command | 权限标识符 |
|---|---|---|
| `alert()` | `message` | `dialog:allow-message` |
| `confirm()` | `ask` | `dialog:allow-ask` |
| `open()` 文件选择器 | `open` | `dialog:allow-open` |
| `save()` 保存对话框 | `save` | `dialog:allow-save` |

## 测试

### 新增 10 个测试用例

**[tests/unit/search.test.ts](file:///workspace/tests/unit/search.test.ts)**（6 个）— replaceAll/replaceCurrent 纯前端逻辑：
- 替换所有匹配项并返回正确数量

- 无匹配时返回 0 且文档不变
- 大小写敏感模式正确替换
- 正则模式替换
- replaceCurrent 仅替换当前匹配项

**[tests/unit/capabilities.test.ts](file:///workspace/tests/unit/capabilities.test.ts)**（4 个）— ACL 配置防回归：
- 包含 `dialog:allow-message`（alert 映射需要）
- 包含 `dialog:allow-ask`（confirm 映射需要）
- 保留 `dialog:allow-open` 和 `dialog:allow-save`
- 包含全部 13 个自定义 app command 权限

全套 **253 个测试通过**（原 243 + 新增 10），`tsc --noEmit` 通过。
