# v3.5.0 设计文档 —— 主题系统（Theme Epic #221）

> 版本：v3.5.0（2026-10-17）
> 范围：自 v3.4.0 起 92 个提交（含 25 个 merge，合并 25 个 PR）/ 181 个文件（+24117 / −1824，不含本版发版文档提交）。
> 主线：Theme Epic #221 —— 从内容级令牌到 Typora 兼容层、主题导入、预装 / 自研主题、导出一致性的全链路；配套主题断言防线与 asset 协议真机探针。

## 1. 背景与目标

v3.4.0 完成智能粘贴后，本项目相对 Typora 最显著的缺口是「主题系统」：此前只有明暗二值 `data-theme` 与一份自定义 CSS 覆盖，无法导入 Typora 生态主题、没有预装主题、导出不跟随主题。本版交付 Theme Epic #221：

- **导入 Typora 主题 CSS 即可用**（#306 兼容层）：用户拿一份 Typora 主题 `.css`，无需改写就能在 InklingMD 里以等价节点生效；
- **主题菜单 + 三条导入路径**（#307）：zip / 文件夹 / 复制，体积分档与安全校验；
- **随包预装 + 自研**（#308 / #226）：3 款 MIT 第三方主题随包分发，4 套自研主题补足风格覆盖；
- **导出一致性**：PNG / HTML / PDF 全部跟随当前主题，Mermaid / KaTeX 跟随；
- **断言防线与真机探针**：把「样式结构」「上游绑定结论」分别用静态 / E2E 断言与真机探针锁住。

非目标（Epic 明文）：不实现 Typora 窗口级 UI 皮肤（侧边栏 / 文件树 / 偏好设置 / 菜单 / 弹层），不引入 Typora 编辑器内核行为。

## 2. 总体架构

### 2.1 级联层与 token 体系

- 层序 `@layer base, theme, user` 唯一声明在 `index.html` 内联（唯一落点）。18 个样式入口全部进 `@layer base`（源码包裹或 `vite.config.ts` 的 `themeBaseLayerPlugin`）。
- token 分族：内容级 `--content-*`（编辑区文字 / 块结构）与外壳级 `--shell-*`（窗口 chrome / 侧边栏 / 标签页）。白名单 `src/theme/token-whitelist.json` 与 `App.css` 自动对账（S2）。新增 token 必须先进白名单，否则 S9 会报幽灵 token。
- CodeMirror 宿主外观（`.cm-*`：字体、行号栏、编辑器底色）只能写在 `EditorView.theme`（`src/lib/codemirror-shared.ts` 等）。依据：CodeMirror 用 style-mod 在运行时把样式以**未分层** `<style>` 注入 `<head>` 首位，未分层恒胜 `@layer base`（与特异性无关）；写在应用 CSS 里的 `.cm-*` 必然失效（#310 评审阻塞项）。CM 主题消费的 token 必须继续被它引用，否则变死 token（S17 反向断言）。

### 2.2 CSP 口径

release 下 `style-src` 必须停留在 `'unsafe-inline'` 模式：`index.html` 内联 `<style>`（层序声明）会让 Tauri codegen 注入 nonce 占位符、运行期把 `'nonce-…'` 追加进 `style-src`，而 CSP3 规定指令含 nonce 时 `'unsafe-inline'` 失效，会让 CodeMirror / 自定义 CSS / mermaid 的运行时 `<style>` 全部被拦。因此 `src-tauri/tauri.conf.json` 用 `security.dangerousDisableAssetCspModification: ["style-src"]` 显式关闭该指令的自动修改（S10 断言锁定）；script-src 的注入保持默认开启。

## 3. Typora 兼容层（#306，PR #314）

`src/theme/typora/rewrite.ts` 是纯函数，输入原样 Typora 主题 CSS，输出改写后的 CSS（可直接注入 `@layer theme`）。

- **选择器映射**：`#write` → `.editor-scroll .milkdown`，恒 2 段前缀（G6-I1：禁止 3–4 段，防止外溢到外壳）；`#write h1..h6` / `p` / `ul,ol,li` / `blockquote` 等剥离 `#write` 后加 2 段前缀；裸标签（`table` / `code` / `img` / `a` / `input`）前缀化——**隔离关键**，不加前缀会命中外壳同名元素。
- **类名映射**：`.md-fences` → `.code-block`、`.md-toc` → `.toc-block`、`.md-inline-math` → `.math-inline`、`.md-math-block` → `.math-display`、`.md-diagram-panel` → `.mermaid-block`、`.md-meta-block` → `.frontmatter-block`、`sup.md-footnote` → `sup.footnote-ref` 等（逐条见矩阵）。
- **显式丢弃**：`.cm-*` / `.CodeMirror-*`（语法高亮归 `codeBlockTheme`，G1）；窗口级 UI 皮肤（`#typora-sidebar` / `#top-titlebar` / `.outline-*` / `.file-node-*` / `.modal*` 等，Epic 非目标，实测 6 款基线主题合计约 520 条）。
- **全局名称前缀化**：`body` / `html` / `:root` / 裸 `*` 收敛到 `.editor-scroll .milkdown`，背景 / 字体作用于编辑区容器，不外溢。
- **活文档登记**：`docs/typora-compatibility-matrix.md` 逐条登记状态（原生 / 映射 / 降级 / 不支持）与判据口径；`scripts/theme-compat-report.ts` 是测量工具 + 纯函数第一处真实调用链路，可对任意主题目录重跑复算。

## 4. 主题包机制（#225，PR #315）

- **主题身份 themeId**：`builtin:<slug>` / `bundled:<slug>` / `user:<slug>`，身份驱动注入与去重。
- **注入**：`injectThemeCss` 把主题 CSS 包进 `@layer theme`，层序 `base → theme → user` 与优先级链不变。
- **快照防闪烁**：自研主题是构建期文本（`AppTheme.css = { kind: "text" }`），同步可得、零闪烁（`isSnapshotEligible` 为假，不走快照）；网络型 CSS 走快照避免首帧无样式。
- **首帧**：`data-theme` 同步就位（light/dark 二值，由 `theme.mode` 派生，不扩取值——自研主题靠变量覆盖做差异）；多窗口收敛。

## 5. 主题导入与菜单（#307，PR #316）

- **Rust 目录 IO**：`src-tauri/src/commands/theme.rs` 扫描 / 递归复制 / zip 解压（含 zip-slip 防护：绝对路径与盘符形态显式拒绝）。
- **导入纯核心**（`src/theme/import*`）：包结构归一化、重名策略、体积分档；安全校验——压缩炸弹按**实际解压字节**计限（不是按压缩后大小，否则可被高压缩比绕过）、`@import` 越界读取拦截（与 `url()` 同判据）。
- **store 接线**：扫描 → 幂等补齐 → 索引落盘 → 读盘补主题 → 三条导入路径 → 移除与隐藏（持久化隐藏位，不物理删除）。
- **菜单 UX**：分组列表（内置 / 预装 / 我的 / 已隐藏）、变体切换、zip·文件夹·复制三条导入路径、打开主题目录、移除与隐藏。
- **预装清单机制**：`src-tauri/resources/themes/manifest.json` 最小字段集 `{ v: 1, themes: [{ slug, css, dir?, name, mode, hiddenByDefault? }] }` + `bundle.resources` + 幂等补齐（N13/N15）：首次启动把清单主题按源副本复制到 `$APPDATA/inklingmd/themes/`，缺失或不一致才复制；身份识别先按 `css`/`dir` 相对路径匹配清单 → `bundled:<slug>`，未命中才 `user:*`。

## 6. 预装第三方主题与许可合规（#308，PR #317）

- 3 款 MIT Typora 主题（Drake / Lapis / Notion，各明暗成对，共 6 个 themeId）随安装包分发（`$RESOURCE/themes/` 只读源副本）。
- **许可合规**：`docs/theme-licenses.json` 逐文件 sha256 登记；`src-tauri/resources/themes/NOTICE` 随包附版权声明与许可全文（逐字节）；`THIRD-PARTY.md` 仓库内署名清单（含修改说明）。字体策略：默认降级系统字体、不内嵌（中文大字体体积过大），未随包字体声明相应 `@font-face` 失效后由系统字体接管。
- **CI 门禁三道**：`check:theme-licenses`（NOTICE / 署名清单与登记、归档许可一致）、`check:theme-manifest`（清单字段、slug 唯一性、文件存在）、`check:theme-notice-drift`（生成物必须与提交一致，手改随包 NOTICE / THIRD-PARTY.md 会被拦）。

## 7. 自研内置主题与导出一致性（#226，PR #321）

### 7.1 自研主题

4 套：技术·亮（`builtin:tech`）/ 技术·暗（`builtin:tech-dark`，成对）/ 纸感阅读（`builtin:sepia`，衬线正文）/ 高对比 a11y（`builtin:contrast`，纯黑边框与文字、强化聚焦环）。

- 主题文件**只写 `:root` 变量块**、不写选择器、不引 at-rule（受信内容，允许覆盖含 `--shell-*` 的全部三层）。
- **正文字体**：新增 content 级 token `--content-font`（白名单 `content` 层）。`App.css` 两块基线同值定义（取原 `:root { font-family }` 同一栈 → 零视觉变化），由 `.editor-scroll .milkdown { font-family: var(--content-font) }` 消费。`builtin:sepia` 覆盖为衬线栈，不再动 `--editor-font`（源码模式保持等宽 / 无衬线，语义分离）。E2E 断言取 `.editor-scroll .milkdown` 的**计算 `font-family`** → 含 `Georgia` 且与 `builtin:light` 基线不同，同时 `--editor-font` 解析值仍为系统栈、不含 Georgia。

### 7.2 导出一致性

共用模块 `src/lib/exportTheme.ts`（三路同一套口径，避免三处各自复刻）：

- **PNG 长图**：离屏容器 `[data-theme] > .editor-scroll > .milkdown` 追加到当前文档，复用 `<head>` 已有样式表（含 `#inkling-theme`，其后代选择器天然命中），不注入第二份主题 CSS；连同 `data-theme-id` 一起复刻（元数据锚点对齐）。
- **HTML 导出**：独立文档，① 层序声明（与 `index.html` 逐字同句）② 内联当前文档样式表（`<style>` 取 `textContent`、`<link>` 同源 fetch，保持顺序 → 各表 `@layer` 归属不变）③ 纸张骨架（未分层、只写结构属性）④ 正文包回 `.editor-scroll > .milkdown` 两层 ⑤ `<html>` 写 `data-theme` / `data-theme-id`。
  - **多表 `@import` 外提（#322）**：多张样式表拼进同一个 `<style>` 后，只有第一张表首的 `@import` 仍合法，其余表的会落到「表中间」被浏览器静默忽略（应用侧认可用户自定义 CSS 的表首 `@import` → 同一份 CSS「应用里生效、导出里失效」）。`buildExportCss` 对每张表复用 `splitLeadingImports`，把各表 `@import` 连同前置 trivia 统一提到产物最前（保持相对顺序）。
- **PDF 打印**：打印上述独立文档；`@media print` 显式 `.editor-scroll { height: auto; overflow: visible }`（应用样式里它是 `height:100% / overflow:auto`，独立文档会裁切内容）。

两条不变量（断言锁住）：纸张骨架不得含颜色 / 字体声明（未分层，会盖掉主题层）；骨架不放进任何层，且在 `@layer` 声明之后。

### 7.3 渲染组件跟随

- **Mermaid**（`src/components/Editor/mermaid-view.ts`）：`mermaidThemeFor(mode)` 映射 `dark → "dark"`、其余 `→ "default"`；`ensureMermaid()` 在主题变化时重新 `initialize`（只换 `theme`，不动 `themeVariables.fontSize`——那是 v2.0.1 修多行节点文字裁切的锁定值）；缓存 key = `<theme>::<src>`（换主题命中旧缓存会保持旧色，故换主题时清空缓存）；主题变化经 `session.applyTheme` 末尾 `notifyThemeChanged(themeId, mode)` 广播 `CustomEvent`，活动图表按 `registerMermaidInvalidator` 登记表逐个重渲染，容器断开自动注销，单回调抛错隔离。
- **KaTeX**：跟随主题，不新增 token 族——现有 `--content-math` 在明暗两块都定义为 `var(--text)`，KaTeX 官方样式多为 `currentColor` 继承，公式颜色自动随 `--text` 翻转；E2E 断言同一公式在明 vs 技术（暗）下的**计算颜色不同**。

## 9. asset 协议真机探针与口径守卫

CI 覆盖不到的两组「上游绑定」结论用真机探针验证。两个探针都须 `pnpm tauri build --debug --no-bundle`（frontendDist + CSP 的打包形态；`cargo build` 的 debug 产物按 `build.devUrl` 加载 `http://localhost:1420/`，无 CSP——两者产物同路径，靠探针自检区分）。

### 9.1 CSP 探针（#309，PR #337）

`scripts/probe-asset-csp.mjs`：**Windows / WebView2 对 `http://asset.localhost` 施加 CSP**。第一版结论跑反了（用了 `cargo build` 的 devUrl 形态、无 CSP），靠阳性对照自检修正——结论是 token 在本平台即承重（去掉 `img-src` token ⇒ asset 图当场被拦）。退出码 0–3，判定顺序：devUrl（3）→ 自检（2）→ 目标判定。

### 9.2 背景图导出探针（#348，PR #349 / #352）

`scripts/probe-asset-bg-export.mjs`：asset URL 作为 **CSS 背景图**交给 `html2canvas(useCORS: true, 未开 allowTaint)` 时导出图里到底有没有这张背景图。`tauri 2.11.5` 实测 **判定通过（exit 0）**：asset 背景图（内联 style 与样式表规则两种声明）都被正常画进画布（采样值 [38,35,38] ≈ 探针图中心 [35,35,35]，容差 30）。根因：asset 协议响应自带 `Access-Control-Allow-Origin`（`src/protocol/asset.rs` 按 `window_origin` 注入），跨源头在位、`useCORS` 生效。**不应改成 `allowTaint`**（会污染 canvas，让 `toBlob` 抛 SecurityError）。退出码 0–5，判定顺序：devUrl（3）→ 渲染超时（5）→ 自检（2）→ 目标判定（0/4）。

### 9.3 口径守卫

- 退出码三处一致：脚本头注释图例 / CONTRIBUTING「依赖升级」退出码表 / `tests/unit/asset-*-probe.test.ts` 逐码对账（v3.5.0 起从已删除的 `docs/asset-csp-309.md`、`docs/theme-builtin-226.md` 迁入 CONTRIBUTING 并改为锚定引言行后的表，避免与其余表格混淆）。
- 挂起防护（#342 / #350）：诊断 `fetch` 带 5s 超时（`AbortSignal.timeout`，CSP 拦是立刻拒绝、一换配置 / 版本 asset 协议既不拒绝也不响应即永久挂起）；`runCase()` 的 html2canvas 带 20s 超时哨兵（html2canvas 1.4.1 的 `CacheStorage.loadImage` 无超时），哨兵名单一来源（写端 `err.name` 与读端 `e.name ===` 都用同一常量，全文件只一处字面量）。
- 错误出口统一取 message 首行剥 ANSI（#342：CDP 分支此前漏取，输出仍是 `Call log:` 多行 + ANSI）；CDP 连不上给可读错误。
- 结论绑定 tauri 版本（#351）：登记的版本与 `src-tauri/Cargo.lock` 由 `tests/unit/asset-bg-probe.test.ts` 对账；升级 tauri 后没同步登记会直接红——那是提醒先重跑探针，不是让你改断言。
