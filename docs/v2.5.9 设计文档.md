依据 GitHub 社区与用户反馈的 32 项历史与演进 Issues，对 InklingMD 全量核心功能（WYSIWYG 所见即所得编辑、代码块懒挂载、Mermaid 矢量图表防抖渲染与平移缩放、KaTeX 公式与自动重编号、多标签页与分屏编辑、大纲与实时光标跟随、外部文件变动冲突 Diff 与安全落盘、跨平台构建与发布等）进行了全景审视与测试闭环。

## 二、问题根因与修复设计

### 2.1 根目录父路径解析缺陷 (`parentDir` & `dirNameOf`)
- **根因分析**：
  - 此前 `parentDir` 与 `dirNameOf` 在提取路径末尾斜杠索引时，若文件位于系统根目录（例如 `/file.md` 或 `C:\file.md`），`idx` 等于 `0` 或 `2`。部分处理逻辑直接使用 `slice(0, idx)` 将根目录截断为了空字符串 `""` 或缺少尾部斜杠的盘符，导致 Rust 权限放行 `allow_asset_dir` 与工作区局部刷新 `refreshTree` 传入非法空路径或异常目录。
- **修复方案**：
  - 规范跨平台分隔符匹配与根路径保护：
    - 当 `idx === 0`（形如 `/file.md` 或 `\file.md`）时，正确保留根目录分隔符 `/` 或 `\`；
    - 当 `idx === 2` 且匹配 Windows 盘符（形如 `C:\file.md` 或 `C:/file.md`）时，正确返回含盘符与分隔符的完整根目录 `C:\` 或 `C:/`；
    - 保留原有一般目录及无分隔符路径的规范行为。
