## 任务 22：全局搜索（`Ctrl+Shift+F`）

### 目标
跨工作区所有 `.md` 文件搜索文本内容，列出匹配的文件、行号、上下文，点击跳转到对应位置。

### 技术方案

**Rust 端**：新增 `search_in_workspace` command，遍历工作区目录读取所有 `.md` 文件，返回匹配结果。

```rust
// src-tauri/src/commands/search.rs
pub struct SearchHit {
    pub path: String,        // 文件完整路径
    pub line: usize,         // 行号（从 1 开始）
    pub column: usize,       // 列号（从 1 开始）
    pub preview: String,     // 该行内容（用于显示）
}

pub struct SearchResult {
    pub path: String,
    pub hits: Vec<SearchHit>,
}

#[tauri::command]
pub fn search_in_workspace(
    root: String,
    query: String,
    case_sensitive: bool,
    use_regex: bool,
) -> Result<Vec<SearchResult>, String>
```

实现要点：
- 递归遍历 `root`，跳过隐藏目录（复用 `list_dir_inner` 的过滤逻辑）
- 只读 `.md` / `.markdown` 文件
- 按行匹配，正则编译失败时返回明确错误
- 单文件大小限制（如 5MB），超大文件跳过并记录
- 结果按文件路径排序，每个文件内的命中按行号排序

**前端**：模态搜索面板，复用现有 SearchPanel 的 UI 风格。

```
src/components/GlobalSearch/
├── GlobalSearchPanel.tsx   # 模态面板
└── GlobalSearchPanel.css
```

- 顶部：搜索框 + 正则开关 + 大小写开关
- 中部：结果树，按文件分组，每组显示文件名 + 命中数，展开显示每条命中的行号 + 预览（命中词高亮）
- 底部：统计「N 个文件，M 处匹配」
- 键盘：`↑` `↓` 导航、`Enter` 跳转、`Esc` 关闭

**跳转逻辑**：点击命中项 → 调 `workspace.openFile(path)` → 编辑器 ready 后通过 `TextSelection.near(doc.resolve(pos))` 定位光标 + `scrollIntoView`。

**快捷键**：`Ctrl/Cmd+Shift+F` 打开面板（在 App.tsx 全局快捷键里注册）。

### 验收
- 工作区 100 个 md 文件，搜常见词 1 秒内出结果
- 正则、大小写开关生效
- 点击命中项正确跳转到对应文件对应行
- 无匹配时显示空状态

## 任务 23：斜杠菜单 `/`

### 目标
空行输入 `/` 弹出块类型选择菜单，键盘上下导航，回车插入对应块；`Esc` 关闭。

### 技术方案

基于 Milkdown 的 `@milkdown/plugin-tooltip` 或自定义 ProseMirror 插件实现。

```
src/components/Editor/slash-menu/
├── slash-menu.ts          # ProseMirror 插件（监听 `/` 输入，弹出浮层）
├── SlashMenuView.tsx      # React 浮层组件
└── slash-commands.ts      # 命令定义（插入标题/列表/代码块等）
```

**命令列表**（首版）：
- 标题 1–6
- 有序列表 / 无序列表 / 任务列表
- 引用块 / 代码块 / 分割线
- 表格（默认 2x2）
- 块级公式 `$$`
- Mermaid 图表
- callout（依赖任务 24，先预留菜单项）
- YAML Front Matter（仅在文档首部时显示）
- `[TOC]` 目录
- 脚注定义

**交互**：
- 输入 `/` 后继续输入文字作为过滤词，模糊匹配命令名
- `↑` `↓` 选择，`Enter` 插入，`Esc` 关闭
- 浮层位置跟随光标，使用 ProseMirror 的 coordsAtPos
- 仅在空行或行首触发，避免误触（如在代码块内不触发）

**实现要点**：用 Milkdown 的 `$command` 注册插入命令，浮层用 React 渲染并挂到 document.body，绝对定位。

### 验收
- 空行输入 `/` 弹出菜单
- 输入 `code` 过滤出"代码块"
- 键盘选择回车插入对应块
- 代码块内输入 `/` 不触发

## 任务 24：callout 提示框

### 目标
支持 GFM callout 语法，渲染成带图标和配色的提示框。

### 语法
```markdown
> [!NOTE]
> 这是一个提示

> [!WARNING]
> 这是一个警告

> [!TIP]
> 这是一个技巧

> [!IMPORTANT]
> 这是重要信息
```

### 技术方案

不新增节点类型，复用 blockquote 节点，通过属性区分类型。

```
src/components/Editor/callout.ts
```

- 解析：remark 插件识别 blockquote 首行的 `[!TYPE]`，转为 blockquote 节点的 `calloutType` 属性
- 渲染：自定义 NodeView，根据 type 应用不同 class（`callout-note` / `callout-warning` / `callout-tip` / `callout-important`）
- 序列化：toMarkdown 时还原 `> [!TYPE]` 语法
- 样式：CSS 定义四种配色 + 图标（用 emoji 或 SVG）

**与现有 blockquote 共存**：无 `[!TYPE]` 的普通引用块保持原样，只有带标记的渲染成 callout。

### 验收
- 输入 `> [!WARNING]` 后跟内容，渲染成红色警告框带 ⚠️ 图标
- 四种类型样式正确
- 切换源码模式能看到原始语法
- 普通引用块不受影响

## 任务 26：编辑位置记忆

### 目标
关闭文件时记住光标位置和滚动位置，重新打开时恢复。

### 技术方案

修改 [workspace.ts](file:///workspace/src/store/workspace.ts)：

- `OpenTab` 扩展字段：`cursorPos: number` / `scrollTop: number`
- 关闭 tab 前，从编辑器读取当前选区和滚动位置存入 tab
- 打开文件后，编辑器 ready 时若 tab 有保存的位置，恢复光标和滚动

```
// 编辑器 onChange/onSelectionChange 时同步 pos 到当前 tab
// closeTab 前先 snapshot 当前编辑器状态
// openFile 后 onReady 时若有 savedPos，dispatch setSelection + scrollTop
```

**持久化**：tab 列表本身不持久化（重启后 tab 列表清空），但可以为最近 N 个文件的位置单独存 localStorage，配合任务 28 的最近文件列表使用。

### 验收
- 长文档滚动到中部，关闭重开后回到中部位置
- 光标停在段落中，关闭重开后光标恢复
- 切换 tab 再切回，位置保持

## 任务 27：文件树重命名/删除/新建

### 目标
侧边栏文件右键支持重命名、删除、新建文件/文件夹。

### 技术方案

**Rust 端**：新增 4 个 command。

```rust
// src-tauri/src/commands/file_ops.rs
#[tauri::command]
pub fn rename_path(from: String, to: String) -> Result<(), String>

#[tauri::command]
pub fn delete_path(path: String, recursive: bool) -> Result<(), String>

#[tauri::command]
pub fn create_file(path: String) -> Result<(), String>

#[tauri::command]
pub fn create_dir(path: String) -> Result<(), String>
```

**前端**：
- 侧边栏文件/文件夹右键菜单：重命名、删除、新建文件、新建文件夹
- 重命名：行内变为 input 框，回车确认，Esc 取消
- 删除：弹确认对话框（尤其是非空文件夹）
- 新建：在当前文件夹下创建，自动进入重命名状态

**store 联动**：
- 重命名/删除后刷新文件树（重新 `listDir`）
- 重命名的文件如果正在 tab 中打开，更新 tab 的 path
- 删除的文件如果正在 tab 中打开，关闭该 tab

### 验收
- 右键文件可重命名，回车生效
- 删除文件弹确认，确认后从树和 tab 中移除
- 新建文件后自动打开并进入编辑
- 重命名正在编辑的文件，tab 标题同步更新

## 任务 28：最近打开文件列表

### 目标
侧边栏顶部显示最近打开的 N 个文件，点击直达。

### 技术方案

修改 [workspace.ts](file:///workspace/src/store/workspace.ts)：

**UI**：侧边栏顶部加一个可折叠的"最近打开"区块，列出文件名（hover 显示完整路径），点击调用 `openFile`。

### 验收

- 列表最多 10 个，超出自动淘汰最旧的

## 实现顺序建议

按依赖关系和独立性排序：

1. **任务 28（最近文件列表）** — 最简单，独立，先热身
2. **任务 26（编辑位置记忆）** — 独立，简单
3. **任务 25（标签页右键 + 拖拽）** — 独立，中等
4. **任务 27（文件树操作）** — 需要 Rust command，中等
5. **任务 24（callout）** — 编辑器插件，中等
6. **任务 23（斜杠菜单）** — 编辑器插件，较复杂
7. **任务 22（全局搜索）** — 需要 Rust command + 前端面板，最复杂放最后

每个任务完成后跑 `pnpm tsc --noEmit` + `pnpm build` 验证，全部完成后更新 README 和需求文档的进度表，打 v0.7.0 tag 发版。
