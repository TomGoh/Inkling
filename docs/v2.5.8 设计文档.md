# v2.5.8 设计文档

## 一、需求背景与目标

为保障 InklingMD 在桌面端与跨平台环境下的长期健壮性与高质量交付，依据《InklingMD 开发与发版规范指南》，对全项目开展了端到端全场景测试审查，重点消除 Rust 后端底层文件 IO、前端复杂交互插件以及多标签/分屏/外部冲突等场景下的测试盲区，建立完整的 Rust + Vitest + Playwright 全链路自动化防护网。

---

## 二、测试盲区分析与架构设计

### 2.1 Rust 后端指令防线 (`src-tauri`)
- **文件原子写入异常与降级**：
  - 在 `save_file_atomic` 中，为目标父目录不存在时自动执行 `create_dir_all` 补充单元测试。
  - 增加大文件写入、覆盖写入、临时文件清理的 CRUD 完整闭环测试。
- **全局检索边界与容错**：
  - 补充超大文件（>2MB）自动跳过、`max_results` 上限截断、特殊符号及目录不存在的鲁棒性测试。
- **符号链接与目录扫描**：
  - 验证递归目录扫描中符号链接安全隔离与防死循环保护。

### 2.2 前端扩展插件与 Store 状态机 (`Vitest`)
- **脚注双向联动 (`footnotes.ts`)**：
  - 编写 `findFootnoteDefPos` 与 `findFirstFootnoteRefPos` 真实 ProseMirror Node/Pos 查找与边界容错测试。
- **数学公式自动重编号 (`formula-numbering.ts`)**：
  - 编写多段公式动态插入、删除时的自动递增重新编号，以及开关禁用时清除 `number` 的状态机测试。
- **书签与最近打开 (`workspace/bookmarks.ts`, `workspace/recents.ts`)**：
  - 验证书签增删、持久化与无效路径过滤。
  - 验证最近打开文件的 10 条上限淘汰与 LRU 顺序调整。
- **生命周期 Hooks**：
  - 验证 `useAutoSave` 防抖写盘与草稿跳过、`useStartupFile` 启动入参与单实例唤醒、`useCtrlWheelZoom` 滚轮字体缩放限制。

### 2.3 核心交互链路端到端覆盖 (`Playwright E2E`)
- **多标签页深度操作 (`tabs-extended.spec.ts`, `tabs-drag-reorder.spec.ts`)**：
  - 覆盖 Tab 右键菜单「关闭其他」、「关闭右侧」、「全部关闭」、「复制路径」。
  - 覆盖鼠标中键关闭 Tab 与 HTML5 原生拖拽重排交互。
- **外部文件变动冲突 (`conflict-dialog.spec.ts`)**：
  - 覆盖触发外部变动时 Conflict 对话框弹出、Diff 对比视图切换、丢弃本地重载磁盘与保留本地继续编辑全分支。
- **分屏双栏对照 (`split-screen.spec.ts`)**：
  - 覆盖从 Tab 右键菜单「在分屏打开」，验证双栏独立渲染。
- **禅模式与专注模式 (`zen-focus-mode.spec.ts`)**：
  - 覆盖通过更多菜单进入禅模式全屏、按 `Esc` 退出恢复，以及段落专注模式的高亮弱化样式生效。
