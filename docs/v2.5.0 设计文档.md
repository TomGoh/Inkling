# InklingMD v2.5.0 架构与设计文档

## 1. 概述与目标
v2.5.0 全面落地了 UI/UX Review 提出的 6 个阶段设计系统重构方案，重点提升整体视觉层次、排版呼吸感与交互质感。

## 2. 核心改动模块

### 2.1 统一 Design Tokens（#79）
- 在 `src/App.css` 建立 4px 栅格变量标尺（`--space-1` 至 `--space-8`）。
- 建立三层背景层级（`--bg-canvas`, `--bg-sidebar`, `--bg-surface`, `--bg-elevated`）与四阶文本阶梯（`--text-primary`, `--text-secondary`, `--text-tertiary`, `--text-faint`）。
- 统一阴影与平滑阻尼过渡曲线（`cubic-bezier(0.16, 1, 0.3, 1)`）。

### 2.2 编辑器排版垂直节奏（#80）
- 正文行高统一提升至 `1.75`，段落边距收敛至 `0.8rem`。
- H1 采用篇章级大上边距（`2.2rem`）并附带极浅下边框分割，H2 上边距调为 `1.8rem`。
- 引用块边框采用柔和的 `3px solid var(--accent)` 并在右侧施加轻微圆角。

### 2.3 顶部工具栏重构与 Command Bar（#81）
- 新增 `MoreMenu` 下拉浮层，收纳低频次操作（全屏、全局搜索、快捷键面板、设置等）。
- 顶栏布局精简为清晰的三栏：左侧文档与保存状态、右侧模式切换胶囊与 `MoreMenu` 菜单，消除传统工具栏图标堆叠。

### 2.4 侧边栏与标签栏精细化（#82）
- 文件树活跃项改用柔和的 Subtle Pill 胶囊全圆角高亮。
- 标签栏增加更加平滑的激活与悬浮过渡。

### 2.5 统一弹窗体系（#83）
- 统一 Modal 浮层阴影、圆角（`10px`~`12px`）与 `menu-in` 平滑微动效。

### 2.6 深色模式校准与响应式适配（#84）
- 深色模式背景、边框及强调色完成体系化映射。
- 引入媒体查询断点（`<960px` 自动折叠大纲，`<768px` 缩小编辑区边距适配窄屏）。
