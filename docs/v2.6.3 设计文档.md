# InklingMD v2.6.3 设计文档

> **版本**：v2.6.3  
> **日期**：2026-08-23  
> **类型**：源码模式大纲联动与模式切换视口无损还原修复（Feature & Bugfix）  
> **关联 Issue**：Fixes #117, Fixes #118  
> **前序版本**：v2.6.2

---

## 1. 背景与目标

在 InklingMD 提供的 WYSIWYG（富文本所见即所得）与 Source Mode（源码模式）双编辑体验中，存在两项影响深度编辑体验的问题：
1. **Issue #117 - [Bug] 模式切换时视口与滚动位置丢失**：用户在长文档编辑时，从富文本切换到源码模式容易从头开始，源码模式切换回富文本模式时位置严重漂移；
2. **Issue #118 - [Feature] 源码模式（Source Mode）支持大纲（Outline）点击跳转与阅读定位联动**：源码模式下大纲面板无法正确提取标题层级，无法点击跳转，也缺乏当前阅读位置的高亮同步跟随。

v2.6.3 旨在彻底解决富文本与源码模式之间的状态无缝流转，打通源码模式下的大纲提取、点击精准定位与阅读高亮双向闭环。

---

## 2. 核心架构与技术方案

### 2.1 模式切换视口与滚动无损还原（Issue #117 修复）

- **根因剖析**：
  - 富文本（Milkdown / ProseMirror）与源码模式（CodeMirror 6）拥有独立的滚动容器（`.editor-scroll` vs `.cm-scroller`）；
  - 从源码模式切回富文本模式时，ProseMirror 重新解析并挂载 DOM，其排版高度需要经历异步重绘沉降周期。原先依赖单次短延迟（`setTimeout(100)`）尝试恢复 `scrollTop`，在 DOM 尚未完全排版稳定时会被浏览器后续的布局重排挤压冲掉，导致视口漂移。
- **架构决策与实现**：
  - 在 `src/components/Editor/Editor.tsx` 与 `useSourceModeTransition.ts` 中引入 **多帧 RAF 布局沉降检测与渐进重试机制（Layout Settlement & RAF Retry）**；
  - 记录精确的 `prosePosToMarkdownOffset` / `markdownOffsetToProsePos` 光标快照与 `scrollTop`；
  - 切回富文本后，连续多帧检测滚动容器高度与位置，当高度收敛稳定后再执行平滑精准复位并确保光标选区正确聚焦，彻底消除漂移。

### 2.2 纯 Markdown 大纲解析与异常边界防御（Issue #118 实现）

- **解析引擎增强 (`src/lib/outline.ts`)**：
  - 新增/重构 `extractMarkdownOutline(markdown: string): EditorOutlineHeading[]`；
  - 自动识别并跳过顶部 YAML Front Matter，引入 **最大 100 行遍历阈值防御**（防止未闭合 frontmatter 导致整篇文档标题丢失）；
  - 自动跳过 ```` ``` ```` 与 `~~~` 围栏代码块内部包含的伪 `#` 标题行；
  - 提取标准 `ATX` 标题（`#` ~ `######`），并同步记录 `index`、`level`、`text`、`pos`（字符偏移量）以及 `line`（行号）。

### 2.3 源码模式大纲点击定位与滚动路由 (`src/lib/source-mode-scroll.ts`)

- **独立滚动通道**：
  - 抽象 `SourceModeScrollManager`，通过 `registerSourceModeScroll` 与 `unregisterSourceModeScroll` 进行按标签页路径绑定的实例隔离；
  - 在 `OutlinePanel.tsx` 中增加多模式分发：富文本模式调用 ProseMirror 的 `findEditorHeadingPos`，源码模式调用 `runSourceModeScrollToHeading`；
  - 源码模式下使用 `EditorView.scrollIntoView({ y: "center" })` 居中定位标题，并执行 `view.dispatch({ selection: { anchor: offset } })` 同步光标。
- **三级级联匹配策略**：
  - 优先按大纲项生成的稳定 `id` 进行快速匹配；
  - 次选 `text + level` 内容匹配；
  - 保底按标题 `index` 序号并在行号附近进行安全夹紧定位，彻底杜绝同名/重复标题点击错位。

### 2.4 阅读定位与大纲双向高亮跟随 (`src/components/Editor/SourceModeEditor.tsx`)

- **状态同步与防抖追踪**：
  - 在 CodeMirror 的 `EditorView.updateListener` 中监听滚动与选区变化；
  - 结合 `requestAnimationFrame` 进行滚动防抖，计算当前顶部可见行与光标位置，反查最近的标题索引；
  - 通过 `onOutlineChange` 向外广播更新后的 `activeIndex`，实时高亮侧边栏大纲面板对应项。
