## 任务 1：HTML 嵌入/行内标签渲染

### 目标

支持在 Markdown 中直接书写 HTML 标签（如 `<span style="color:red">`、`<kbd>Ctrl</kbd>`、`<details>`、`<mark>`、`<blockquote>`），编辑器真实渲染而非原样显示文本。同时保证安全（过滤 XSS）和性能（不拖慢编辑）。

### 问题根因

commonmark preset 的 `htmlSchema` 是 inline atom 节点，默认 `toDOM` 把 HTML 字符串作为 `textContent` 写入 span，浏览器转义显示为字面文本（如看到 `<span style="color:red">红色</span>` 文字而非红色文字）。

### 技术方案

新建 [html-view.ts](file:///workspace/src/components/Editor/html-view.ts)：用 `$view` 覆盖 `htmlSchema.node` 的 NodeView。

```typescript
import { htmlSchema } from "@milkdown/kit/preset/commonmark";
export const htmlView = $view(htmlSchema.node, () => createHtmlView());
```

#### 1.1 白名单过滤（安全核心）

```typescript
const ALLOWED_TAGS = new Set([
  "span", "a", "b", "i", "u", "s", "em", "strong", "code", "kbd", "sub", "sup",
  "small", "mark", "br", "abbr", "cite", "q", "time", "var", "samp",
  "div", "p", "details", "summary", "blockquote", "pre", "ul", "ol", "li",
  "h1", "h2", "h3", "h4", "h5", "h6", "hr", "table", "thead", "tbody", "tr", "th", "td",
  "img",
]);
```

三层过滤：
1. **标签白名单**：不在白名单的标签直接丢弃（script/iframe/object/embed 等）
2. **属性白名单**：全局属性（class/style/title/id/lang/dir）+ 标签专属属性（a 的 href/target、img 的 src/alt 等）；`on*` 事件属性全部移除
3. **CSS 属性白名单**：style 逐条解析，仅保留 color/font/text/border/padding/margin 等安全属性；拦截 `expression()`、`javascript:`、`behavior`、`-moz-binding` 等 CSS 注入
4. **URL 协议检查**：href/src 仅允许 http/https/mailto/tel/锚点/相对路径/data:image，过滤 `javascript:` 和非图片 `data:`

#### 1.2 DOMParser 解析（比 innerHTML 安全）

```typescript
const doc = new DOMParser().parseFromString(value, "text/html");
// 遍历 doc.body.childNodes，白名单克隆到 DocumentFragment
```

DOMParser 解析时不执行 script、不加载资源，比 `innerHTML` 安全。递归遍历解析后的 DOM 树，白名单克隆到 DocumentFragment。

#### 1.3 LRU 缓存（性能核心）

```typescript
const SANITIZE_CACHE = new Map<string, globalThis.Node>();
const CACHE_LIMIT = 200;

function cacheGet(key: string): globalThis.Node | undefined {
  const node = SANITIZE_CACHE.get(key);
  if (node !== undefined) {
    // LRU：命中移到末尾
    SANITIZE_CACHE.delete(key);
    SANITIZE_CACHE.set(key, node);
  }
  return node;
}
```

- **缓存 key**：原始 HTML 字符串（value）
- **缓存 value**：sanitized DocumentFragment
- **命中**：返回 `cloneNode(true)`（避免多节点共享 DOM 引用导致冲突）
- **淘汰**：满 200 条淘汰最旧（Map 首个 key）
- **效果**：相同 HTML 只解析一次，后续命中缓存 O(1) 返回克隆

#### 1.4 NodeView update 优化

```typescript
update: (next: PMNode) => {
  if (next.type.name !== "html") return false;
  const nextValue = (next.attrs.value as string) ?? "";
  if (nextValue === current) return true; // 值未变，跳过重渲染
  current = nextValue;
  render(nextValue);
  return true;
},
```

ProseMirror 每次 doc 变更会调用所有 NodeView 的 update。这里先比对 value，未变直接 return true 跳过重渲染，避免无谓的 DOM 操作。

#### 1.5 块级 HTML 处理

commonmark 的 html 节点是 inline atom，块级 HTML 会被 `remarkHtmlTransformer` 包进段落。NodeView 外层用 `<span>`（保持 inline 结构合法），块级 HTML 时加 `display: inline-block` + `html-block` class，视觉上呈现块级效果但不破坏 ProseMirror 文档结构。

```typescript
if (isBlock) {
  dom.style.display = "inline-block";
  dom.classList.add("html-block");
}
```

### 性能要点
- LRU 缓存（200 条）消除重复解析
- update 比对 value 跳过无变更的重渲染
- DOMParser 一次性解析（非逐标签 innerHTML）
- 白名单过滤是纯遍历，无正则回溯风险

### 验收
- `<span style="color:red">红色</span>` 渲染为红色文字
- `<kbd>Ctrl</kbd>` 渲染为键盘按键样式
- `<details><summary>` 渲染为可折叠块
- `<script>alert(1)</script>` 被过滤，不执行
- `onclick="..."` 等事件属性被移除
- `javascript:` 协议的 href 被过滤
- 相同 HTML 重复渲染命中缓存，不重复解析

## 任务 2：脚注支持

### 目标

支持 GFM 脚注语法 `[^1]` 引用 + `[^1]: 定义`，点击引用跳转定义，点击返回链接跳回首个引用。

### 现状确认

脚注功能**在 v0.5.0 已完整实现**，本次仅确认可用并补充示例：
- GFM preset 自带 `footnoteReferenceSchema` / `footnoteDefinitionSchema`（[footnotes.ts](file:///workspace/src/components/Editor/footnotes.ts) 第 13-16 行导入）
- [footnotes.ts](file:///workspace/src/components/Editor/footnotes.ts) 覆盖 NodeView 提供跳转交互
- [Editor.tsx](file:///workspace/src/components/Editor/Editor.tsx) 第 260-261 行已注册
- [App.css](file:///workspace/src/App.css) 第 703-745 行有样式

用户反馈"好像没有支持"实为写法问题。正确写法需**同时**包含引用和定义：

```markdown
正文[^1]这里。

[^1]: 这是脚注内容。
```

注意：引用和定义之间需空行，定义需顶格写。本次在 mock 工作区新增 `footnote-demo.md` 示例文件供验证。

### 验收
- `[^1]` 渲染为上标 `[1]`，点击跳转到定义
- `[^1]: 内容` 渲染为 `[1]: 内容 ↩`，点击 ↩ 跳回首个引用
- 支持任意标识符（`[^note]`）

## 任务 3：Mermaid 下载与缩放

### 目标

Mermaid 图表新增「下载」按钮导出 SVG 文件；鼠标悬停图表时 `Ctrl/Cmd+滚轮` 缩放 SVG（0.5~3x），不触发文档缩放。

### 技术方案

修改 [mermaid-view.ts](file:///workspace/src/components/Editor/mermaid-view.ts)。

#### 3.1 工具栏与下载按钮

```typescript
const toolbar = document.createElement("div");
toolbar.className = "mermaid-toolbar";
container.appendChild(toolbar);

const downloadBtn = document.createElement("button");
downloadBtn.textContent = "下载";
toolbar.appendChild(downloadBtn);
```

工具栏 CSS：`position: absolute; opacity: 0`，`.mermaid-block:hover .mermaid-toolbar { opacity: 1 }`，hover 显现避免遮挡图表。

#### 3.2 SVG 下载（双端）

```typescript
async function downloadSvgFile(svg: string): Promise<void> {
  const blob = new Blob([svg], { type: "image/svg+xml" });
  const filename = `mermaid-${stamp}.svg`;
  if (isTauri()) {
    const path = await save({ defaultPath: filename, filters: [{ name: "SVG", extensions: ["svg"] }] });
    if (!path) return;
    await writeBinaryFile(path, new Uint8Array(await blob.arrayBuffer()));
  } else {
    // 浏览器端 a 标签触发下载
  }
}
```

- 桌面端：`save` 对话框选路径 + `writeBinaryFile` 写入
- 浏览器端：`URL.createObjectURL` + `<a download>` 点击下载
- 渲染时缓存 `lastSvg` 字符串，下载直接取用，不重新渲染

#### 3.3 Ctrl+滚轮缩放

```typescript
container.addEventListener("wheel", (e) => {
  if (editing) return;
  if (!(e.ctrlKey || e.metaKey)) return;
  e.preventDefault();
  e.stopPropagation();
  const next = e.deltaY < 0 ? zoom + 0.1 : zoom - 0.1;
  zoom = Math.min(3, Math.max(0.5, Math.round(next * 10) / 10));
  applyZoom();
}, { passive: false });

const applyZoom = () => {
  const svg = diagram.querySelector("svg");
  svg.style.transform = `scale(${zoom})`;
};
```

- 用 CSS `transform: scale` 缩放（不触发布局重排，性能优于 width/height）
- `transform-origin: center` 保持居中缩放
- 缩放范围 0.5~3，步进 0.1，一位小数修正避免浮点累积
- `stopPropagation` 阻止冒泡，避免触发文档缩放

#### 3.4 文档缩放排除

修改 [App.tsx](file:///workspace/src/App.tsx) 的 wheel 监听：

```typescript
const onWheel = (e: WheelEvent) => {
  if (!(e.ctrlKey || e.metaKey)) return;
  // Mermaid 图表内部由其 NodeView 的 wheel 监听接管缩放
  const target = e.target as HTMLElement | null;
  if (target?.closest("[data-mermaid]")) return;
  e.preventDefault();
  useSettings.getState().adjustEditorZoom(e.deltaY < 0 ? ZOOM_STEP : -ZOOM_STEP);
};
```

App.tsx 的 wheel 监听是 `capture: true`（先于 mermaid-block 的 bubble 监听执行），需检查 target 是否在 `[data-mermaid]` 内，是则跳过文档缩放，让 mermaid-block 自己处理。

### 性能要点
- 下载按钮 hover 显现，不占布局空间
- SVG 字符串渲染时缓存，下载不重新渲染
- 缩放用 transform 不触发布局重排
- wheel 监听只在 Ctrl 时处理，普通滚动不拦截

### 验收
- Mermaid 图表 hover 显示「编辑」「下载」按钮
- 点击「下载」弹出保存对话框（桌面端），保存为 SVG 文件
- 鼠标在图表上 `Ctrl/Cmd+滚轮` 缩放 SVG，不影响文档缩放
- 缩放范围 0.5~3，步进 10%
