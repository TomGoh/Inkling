# InklingMD v2.5.1 架构与设计文档

## 1. 概述与目标
v2.5.1 针对近期版本迭代反馈与 Code Review 提出的问题进行了专项修复与完善，重点解决 Mermaid 矢量图表渲染失效、顶栏冗余按钮收拢、防抖序列化状态丢失防护、图片缓存 LRU 淘汰策略以及跨平台搜索排序确定性问题。

## 2. 核心改动模块

### 2.1 Mermaid 渲染与 SVG 命名空间修复
- **问题分析**：在 HTML/SVG 安全白名单清洗（`html-view.ts`）时，对 SVG 元素错误使用了 `document.createElement`（HTML 命名空间），导致浏览器无法将其当作标准 SVG 矢量图形解析，致使 Mermaid 图表全部显示异常；此外 SVG 属性过滤未保留驼峰命名，且缺少渐变与滤镜标签支持。
- **解决方案**：
  1. `cloneFiltered` 递归克隆 SVG 节点及其子元素时统一使用 `document.createElementNS("http://www.w3.org/2000/svg", tag)`。
  2. 扩展白名单，加入 `linearGradient`、`radialGradient`、`stop`、`pattern`、`filter`、`feGaussianBlur` 等 SVG 规范标签。
  3. 保留 SVG 关键属性的原始大小写（如 `viewBox`、`gradientUnits`、`stopColor` 等）。

### 2.2 顶栏交互收纳优化
- 移除 `EditorTopbar.tsx` 外层单独的齿轮设置直达按钮，全面统一收纳进 `···`（更多操作）菜单项中。
- 同步优化 Playwright E2E 测试辅助函数（`openSettings` 通过 `···` 菜单触发），保持 UI 规范与自动化测试脚本一致。

### 2.3 编辑器序列化防抖保护（State Protection）
- 在标签页切换（`switchTab`）与关闭（`closeTab`）等破坏性或状态转移操作发生前，主动调用 `flushAllMarkdownPublishers()`，确保最近 200ms 内的按键内容完整同步到 store 中，杜绝丢字或数据未同步。

### 2.4 本地图片缓存 LRU 淘汰策略
- 在 `resolveImageSrc` 中增加缓存命中更新：当命中 `imageSrcCache` 时，先从 Map 中 `delete` 再重新 `set` 到末尾，确保高频访问的图片资源在达到 500 个上限时不会被误淘汰。

### 2.5 Rust 工作区搜索结果确定性
- 在 `search_in_workspace` 递归扫描工作区后执行 `files.sort()` 排序，消除不同操作系统目录遍历随机性，确保 5000 条截断上限下搜索结果跨平台确定一致。
