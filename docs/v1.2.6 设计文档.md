## 任务：块级公式插入修复

### 目标

修复用户反馈的「插入公式还是不能用，不管是/插入还是工具栏插入」：点击斜杠菜单「块级公式」或工具栏「∑ 公式」按钮后，看不到任何效果。

### 问题根因

`math_display` 节点定义（[math.ts](file:///workspace/src/components/Editor/math.ts#L67-L108)）：

```typescript
export const mathDisplaySchema = $nodeSchema("math_display", () => ({
  group: "block",
  atom: true,        // 原子节点：光标无法进入节点内部
  selectable: true,
  attrs: {
    value: { default: "", validate: "string" },
    number: { default: null },
  },
  // ...
}));
```

插入逻辑（[block-commands.ts](file:///workspace/src/components/Editor/block-commands.ts) 与 [slash-menu.ts](file:///workspace/src/components/Editor/slash-menu.ts)）创建空节点：

```typescript
schema.nodes.math_display.create();  // value = ""
```

NodeView 的 `render("", null)` 执行：

```typescript
katex.renderToString("", { displayMode: true, throwOnError: false });
// 输出：<span class="katex">...</span> 但内容为空
```

**三个问题叠加**：
1. `atom: true`：光标无法进入节点，无法直接输入公式
2. 空 value：KaTeX 渲染空字符串，DOM 无可见内容
3. 用户不知道要双击节点才能编辑（因为看不到任何东西可以双击）

结果：节点已插入文档，但用户看不到，以为「不能用」。

### 技术方案

#### 1. 插入后自动进入编辑模式

在 `insertMathBlock`（工具栏）和斜杠菜单的公式命令中，插入节点后：
1. 用 `NodeSelection` 选中刚插入的 atom 节点
2. 通过 `view.nodeDOM(pos)` 获取节点 DOM
3. dispatch `dblclick` 事件触发 NodeView 的 `startEdit`（双击进入编辑模式是已有逻辑）

```typescript
export function insertMathBlock(view: EditorView): void {
  const t = view.state.schema.nodes.math_display;
  if (!t) return;
  const node = t.create();
  const { $from } = view.state.selection;
  const parent = $from.parent;
  let nodePos: number;
  if (parent.type.name === "paragraph" && parent.content.size === 0) {
    const start = $from.before($from.depth);
    view.dispatch(
      view.state.tr
        .replaceWith(start, start + parent.nodeSize, node)
        .scrollIntoView(),
    );
    nodePos = start;
  } else {
    const pos = $from.after($from.depth);
    view.dispatch(view.state.tr.insert(pos, node).scrollIntoView());
    nodePos = pos;
  }
  // 下一帧等 NodeView DOM 挂载后，选中节点并触发双击进入编辑模式
  requestAnimationFrame(() => {
    try {
      const sel = NodeSelection.create(view.state.doc, nodePos);
      view.dispatch(view.state.tr.setSelection(sel));
      const dom = view.nodeDOM(nodePos) as HTMLElement | null;
      if (dom) {
        dom.dispatchEvent(new MouseEvent("dblclick", { bubbles: true }));
      }
    } catch {
      // 位置无效时静默失败
    }
  });
  view.focus();
}
```

**关键点**：
- `requestAnimationFrame`：等 ProseMirror 完成 DOM 更新和 NodeView 挂载后再触发双击，否则 `view.nodeDOM` 可能返回 null
- `NodeSelection.create`：atom 节点用 NodeSelection 选中（不能用 TextSelection）
- `dblclick` 事件触发 NodeView 的 `dom.addEventListener("dblclick", startEdit)` 回调

#### 2. 空值占位提示

修改 NodeView 的 `render` 函数，空 value 时显示虚线占位框，避免 KaTeX 渲染空字符串导致节点不可见：

```typescript
const render = (value: string, number: number | null) => {
  dom.setAttribute("data-value", value);
  // 空公式：显示占位提示，避免 KaTeX 渲染空字符串导致节点不可见
  if (!value) {
    dom.classList.add("math-empty");
    dom.innerHTML = displayMode
      ? '<span class="math-placeholder">双击编辑公式</span>'
      : '<span class="math-placeholder">公式</span>';
    return;
  }
  dom.classList.remove("math-empty");
  // ... 正常 KaTeX 渲染
};
```

```css

```

### 交互流程

| 操作 | 效果 |
|---|---|
| 工具栏点击「∑ 公式」 | 插入空 math_display 节点 → 自动选中 → 自动进入编辑模式（textarea 弹出，光标在内） |
| 斜杠菜单 `/公式` | 同上 |
| 插入后输入 LaTeX | textarea 实时编辑，失焦或点别处 commitEdit 提交 |
| 提交后空值 | 显示虚线占位框「双击编辑公式」 |
| 双击占位框 | 重新进入编辑模式 |
| 提交后有值 | KaTeX 正常渲染公式 |

### 验收

- 工具栏「∑ 公式」点击后立即弹出 textarea 可输入
- 斜杠菜单「块级公式」点击后立即弹出 textarea 可输入
- 输入 LaTeX 后失焦，公式正确渲染
- 空公式节点显示虚线占位框，不会「看不见」
- 双击空公式占位框可重新进入编辑模式
- schema 无 math_display 时不报错
