## 任务：Mermaid 图表拖动平移

### 目标

v1.2.3 已支持 Mermaid 图表 `Ctrl/Cmd+滚轮` 缩放（0.5~3x），但放大后只能通过 mermaid-block 的横向/纵向滚动条查看不同区域，交互不便。本版补齐拖动平移：放大后按住鼠标直接拖动图表查看各区域。

### 问题分析

当前 [mermaid-view.ts](file:///workspace/src/components/Editor/mermaid-view.ts) 的缩放实现：

```typescript
svg.style.transformOrigin = "center";
svg.style.transform = `scale(${zoom})`;
```

`transform: scale` 不改变布局尺寸，放大后 SVG 视觉溢出 mermaid-render 容器。mermaid-block 有 `overflow-x: auto`，但只处理横向，且用户需要找滚动条拖动，不如直接按住图表拖动自然。

### 技术方案

#### 1. transform 扩展为 translate + scale

```typescript
let panX = 0; // 平移 X（像素，缩放后坐标系）
let panY = 0;

const applyZoom = () => {
  const svg = diagram.querySelector("svg");
  if (!svg) return;
  svg.style.transformOrigin = "center";
  // translate 叠加在 scale 之上：先以中心缩放，再整体平移 panX/panY
  svg.style.transform = `translate(${panX}px, ${panY}px) scale(${zoom})`;
  diagram.classList.toggle("zoomable", true);
  diagram.classList.toggle("pannable", zoom > MERMAID_ZOOM_DEFAULT);
};
```

- `transform-origin: center`：scale 以中心为原点，放大后中心保持不变
- `translate(panX, panY) scale(zoom)`：transform 从右到左应用，先 scale 再 translate，平移量是缩放后的像素坐标，符合直觉

#### 2. 拖动事件处理

```typescript
let dragging = false;
let dragStartX = 0, dragStartY = 0;
let panStartX = 0, panStartY = 0;

const onMouseMove = (e: MouseEvent) => {
  if (!dragging) return;
  panX = panStartX + (e.clientX - dragStartX);
  panY = panStartY + (e.clientY - dragStartY);
  applyZoom();
};
const onMouseUp = () => {
  if (!dragging) return;
  dragging = false;
  diagram.classList.remove("dragging");
};

diagram.addEventListener("mousedown", (e) => {
  if (editing) return;                    // 编辑模式不响应
  if (zoom <= MERMAID_ZOOM_DEFAULT) return; // 仅放大时可拖动
  if ((e.target as HTMLElement).closest(".mermaid-toolbar")) return; // 排除工具栏
  e.preventDefault();
  e.stopPropagation();
  dragging = true;
  dragStartX = e.clientX;
  dragStartY = e.clientY;
  panStartX = panX;
  panStartY = panY;
  diagram.classList.add("dragging");
});
window.addEventListener("mousemove", onMouseMove);
window.addEventListener("mouseup", onMouseUp);
```

**关键设计**：
- `mousemove`/`mouseup` 挂在 **window** 上而非 diagram，避免拖出图表区域后鼠标事件丢失（鼠标移到图表外仍能继续拖动）
- `mousedown` 挂在 diagram 上，`e.preventDefault()` 防止选中文本，`e.stopPropagation()` 防止 ProseMirror 抢焦点
- 仅 `zoom > 1` 时响应拖动（zoom=1 图表完整显示，拖动无意义）
- 排除点击工具栏按钮（`.mermaid-toolbar`）的情况

#### 3. destroy 钩子清理监听器

NodeView 接口支持 `destroy()` 方法，在节点被移除时调用。新增清理 window 监听器避免内存泄漏：

```typescript
return {
  dom: container,
  update: (next: Node) => { ... },
  stopEvent: () => editing,
  ignoreMutation: () => true,
  destroy: () => {
    window.removeEventListener("mousemove", onMouseMove);
    window.removeEventListener("mouseup", onMouseUp);
  },
};
```

#### 4. 双击重置缩放与平移

v1.2.3 双击进入编辑。本版改为：
- `zoom > 1`：双击重置缩放与平移到 100%（放大后想回原状，双击即可）
- `zoom = 1`：双击进入编辑（保持原行为）

```typescript
container.addEventListener("dblclick", (e) => {
  e.preventDefault();
  e.stopPropagation();
  if (editing) return;
  if (zoom > MERMAID_ZOOM_DEFAULT) {
    resetZoomPan(); // zoom=1, panX=0, panY=0
    return;
  }
  enterEdit();
});
```

#### 5. 重新渲染时重置平移

图表内容变化重新渲染时，旧平移量对新图表无意义，重置 panX/panY（保留 zoom，用户仍想保持放大状态查看新图表）：

```typescript
const render = async (value: string) => {
  ...
  diagram.innerHTML = svg;
  lastSvg = svg;
  panX = 0;
  panY = 0;
  applyZoom();
  ...
};
```

#### 6. CSS 光标与溢出

```css
/* 平移：放大后可拖动，裁剪超出部分避免出现双滚动条 */
.editor-scroll .milkdown .mermaid-render.pannable {
  cursor: grab;
  overflow: hidden;
}
.editor-scroll .milkdown .mermaid-render.pannable.dragging {
  cursor: grabbing;
  user-select: none;
}
```

- `cursor: grab` / `grabbing`：光标提示可拖动
- `overflow: hidden`：放大后 SVG 视觉溢出时裁剪，避免与 mermaid-block 的 `overflow-x: auto` 叠加产生双滚动条
- `user-select: none`：拖动时防止选中图表内文本

### 交互流程

| 用户操作 | 状态变化 | 效果 |
|---|---|---|
| Ctrl+滚轮向上 | zoom += 0.1（夹到 3） | 图表放大，pannable class 生效，光标变 grab |
| Ctrl+滚轮向下 | zoom -= 0.1（夹到 0.5） | 图表缩小，zoom 回到 1 时 pannable 移除 |
| zoom>1 时按住鼠标拖动 | panX/panY 更新 | 图表跟随鼠标平移，光标变 grabbing |
| 释放鼠标 | dragging=false | 停止拖动，光标回 grab |
| zoom>1 时双击 | zoom=1, panX=0, panY=0 | 重置缩放与平移 |
| zoom=1 时双击 | 进入编辑模式 | 切换 textarea 编辑源码 |
| 图表内容变化重新渲染 | panX=0, panY=0（保留 zoom） | 重置平移，保持缩放 |
| 节点被删除 | destroy() 清理 window 监听器 | 无内存泄漏 |

### 验收

- 放大图表后按住鼠标可拖动平移，无需调滚动条
- 拖动时光标变 grabbing，释放后回 grab
- 拖出图表区域后继续拖动仍有效（window 监听）
- zoom=1 时不可拖动（图表完整显示）
- 编辑模式下不可拖动
- 双击放大状态重置缩放与平移
- 双击原始大小进入编辑
- 重新渲染图表重置平移
- 节点删除后无 window 监听器残留
